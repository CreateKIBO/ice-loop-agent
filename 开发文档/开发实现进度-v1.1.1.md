# v1.1.1 安装升级自动停止 Agent

2026-10-03。已完成用户要求：安装前自动停止当前 Agent，等待本产品后台进程退出后继续安装。

## 实现

- 接入 NSIS `customCheckAppRunning`，验证同一 Windows 会话的本产品进程与子进程，正常关闭等待 8 秒后再结束残留；不批量关闭无关 Python/Electron。
- 通过 PID 和创建时间保持已验证的进程身份，避免 Windows 退出时清空程序路径引起误判，也避免 PID 复用造成误杀。无法确认/无法关闭则在替换文件前退出并报错。
- 保护旧安装目录内工作区：同卷暂存至安装目录外，写入恢复清单，安装成功或正常失败退出后放回原路径。断电/强制结束时暂存数据继续保留。
- 安装载荷改用 ZIP 直接解压，保留结果检查，不使用差分载荷；文章引擎业务代码和 v1.1 功能保持。
- 重新生成 v1.1.1 安装程序与免安装包，并更新载荷/源码一致性审计。
