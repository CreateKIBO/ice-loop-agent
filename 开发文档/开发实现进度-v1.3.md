# v1.3 对话创作工作台实现进度

日期：2026-10-04。用户已选择浅色三栏并授权开始升级。

本版从 [设计方案](v1.3-对话创作工作台设计方案.md) 落地独立「创作对话」和「文章审批」，继续复用已有文章、模型、资源及内嵌网页工作台。

| 项目 | 实现 |
| --- | --- |
| 三栏桌面工作台 | 最近会话、对话输入、文章/差异/配图预览，可拖动、折叠及窄窗口切换 |
| 开源组件 | Shoelace 分栏/标签与 Lucide 图标，本地构建，带许可证 |
| 会话 | 流式讨论、停止、重试、改名、搜索、归档恢复、消息分支 |
| 历史与选题 | 当前栏目前五篇正文、全部标题、发布进度、对应期大纲，栏目子目录索引 |
| 材料与编辑 | 引用历史文章、导入 MD/TXT/DOCX、选段指令、候选手改、多版本 |
| 国内模型 | 共用原模型配置和凭据，多轮上下文、流式及结构化候选 |
| 审批 | 幂等提交、采用/退回、审批手改、意见写回对话 |
| 共享文章 | 草稿及普通制作任务双向读取/采用；历史原文件和只读原稿保留 |
| 冲突保护 | 原稿 hash 校验、已采用关联检查、未保存编辑保护、账户上下文隔离 |
| 配图交接 | 审批采用稿无模型重写地进入补图流程，保留提示词和栏目期号 |
| 浏览器及交付 | TapNow 中国站、微信公众号网页仍内嵌；文本/图片发布包仍手动导入 |
| 数据升级 | 增量数据库表、升级前数据库快照，复用安装时停机/工作区恢复 |

差异视图目前以按顺序匹配的共同前缀/后缀标记整段变化范围，支持重复行和段落移动；未实现字符级最小差异或三方自动合并。选中段落提供自定义指令，没有为每种改稿动作增加独立菜单。消息超过最近二十条时只将最近二十条完成消息作为多轮上下文，当前文章和显式引用仍带入。

原有自动准备工作流保留给已建立的制作任务；主要新建/改稿入口统一到创作对话。讨论时不强制按原选题、大纲、标题的弹窗逐关操作，最终采用仍进入独立审批。公众号正式发布和 TapNow 实际生图继续由用户操作。
