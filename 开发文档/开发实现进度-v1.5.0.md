# v1.5.0 创作体验迭代

本轮围绕持续写作、多公众号切换与文章审批改善桌面体验。设计取舍来自 LibreChat 的独立文章面板、Open WebUI 的文档旁对话和快捷搜索；实际组件使用现有 Shoelace / Lucide，并增加 Motion 14.0.0。没有改变已有 Markdown 数据格式。

## 已实现

| 部分 | 行为 |
|---|---|
| 导航与检索 | 侧栏头尾固定、中段独立滚动；整体收起；Ctrl K 查当前公众号的会话、草稿、制作任务和页面；键盘选择与跳转 |
| 创作流程 | 从讨论、初稿保存、审批到配图与导出的真实状态提示；首条直接输入可以衔接创建会话；取消仍保留文字 |
| 编辑体验 | 未发送输入按账号与会话自动保留；写作快捷指令；引用和选中文段移除；字符与段落统计；专注阅读与回到最新 |
| 运行反馈 | 真实阶段、用时、接收字符数；Motion 驱动页面、弹窗、消息和运行状态；同阶段轮询不重复入场 |
| 显示偏好 | 舒适 / 紧凑密度；开启动效 / 跟随系统 / 减少动效；系统减少动效始终生效 |
| 内置浏览器 | 收起侧栏及小窗口时网页区域自适应；网页内 Ctrl K 打开本地搜索；弹窗打开时隐藏原生网页，关闭恢复 |
| 可靠性 | 搜索跳转后重开请求、旧关闭事件、旧消息 DOM 保留、生成时继续输入、公众号切换期间旧输入隔离 |

## 实现位置

- `desktop/renderer/navigation-ux.js`：本地搜索、导航门、侧栏行为。
- `desktop/renderer/writing-ux.js`：输入恢复、写作指令、阅读工具、账号与挂载上下文保护。
- `desktop/renderer/studio-experience.js` / `.css`：状态提示、显示偏好、通用视觉规则。
- `desktop/renderer/motion-entry.js`：实际 Motion 接入、取消及减少动效策略；`desktop/build-components.cjs`：离线打包与许可证复制。
- `creative-chat.js` / `publication.js`：首条消息、轮询与账号切换的核心状态保护。
- `desktop/browser.cjs` / `preload.cjs`：内置网页中的固定快捷键通知；远程网页不获得本地工作区接口。

## 使用与验收

使用说明见 `ice-loop-agent/docs/v1.5-升级说明.md`；设计和调研见 `design-system-v1.5.md`、`v1.5-research.md`；源码复审见 `v1.5-review.md`。最终执行结果、安装包哈希和真实桌面截图统一归档在 `docs/v1.5-验收结果.json` 与 `docs/screenshots/v1.5/`。

本轮测试采用隔离工作区、离线模型和本地网页夹具，不改动个人文章，不调用付费模型，不登录 TapNow 或公众号后台，不替用户发布。公开网站的只读观察单独记录，不把空 DOM 或截图超时算作完整网站体验通过。安装器校验载荷与源码；实际安装向导由用户运行。

保留旧版本发布包及开发记录。新安装包和 ZIP 均为 v1.5.0，运行目录与测试、构建产物位于 G 盘。

## 最终结果（2026-10-05）

60 项 Node 测试通过；源码版和打包版各 85 项创作桌面检查、25 项内置浏览器检查通过。实际操作涵盖初稿生成/保存/审批、会话与任务删除归档恢复、快捷搜索、输入恢复、账号隔离、动效偏好、阅读位置保留及内置网页布局。最后一轮运行未发现意外 JavaScript 错误。相同断言在两种运行形态下复验，不累加为独立功能数量。

32 张真实截图和最终日志索引已归档。源码与 ASAR、安装器及 ZIP 载荷与最终程序、内置引擎与最后构建完全一致，包内没有个人文章、账号登录状态或 API Key。最终产物：`ice-loop-agent/release/ICE-Loop-Studio-1.5.0-Setup.exe`、`ice-loop-agent/release/ICE-Loop-Studio-1.5.0-x64.zip`。安装器载荷已经实际提取核对，本轮未执行用户安装向导。
