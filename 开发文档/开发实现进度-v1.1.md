# v1.1 内嵌浏览器与手动发布包实现进度

2026-10-02。本轮按用户新要求完成：TapNow 必须在 Agent 内部使用，增加微信公众号后台网页入口，导出为纯文本 Markdown 和图片两个文件夹，用户手动上传发布。

## 已完成

1. 左侧「网页工作台」，TapNow 与微信公众号后台两个页签；所有既有 TapNow 按钮改为内部入口。Chromium 随程序提供，无需另外安装 Chrome。
2. 地址栏、前进/后退、刷新/停止、站点首页。HTTPS 登录弹窗在程序内部作为子窗口打开，下载使用原生保存窗口，可选择目标位置，默认保存在非 C 盘工作区。
3. 按公众号和站点隔离持久会话；切页保留网页，切换公众号关闭旧视图后重建独立会话。清除当前站点登录不影响其他站点和公众号。会话不进入备份或交付包。
4. 远端网页关闭 Node、无本地 preload，不能调用本地引擎或读取模型 Key；禁止进入本地协议/文件/脚本地址。视图随窗口大小和滚动调整，打开本地弹窗时隐藏。
5. 默认「发布包」顶层只有「文本」「图片」。文本包含 UTF-8 `01-公众号正文.md` 与 `02-发布信息.txt`；图片只包含当前已审核选用且验证有效的配图。正文保留代码块，图片链接为 `../图片/文件名`，未完成任务明确标注草稿与缺图。
6. 普通文章与已有文章补图使用同一发布包导出器。内部证据、运行源码、审核文档和 HTML 预览另行保留，不混入发布包。
7. 重复导出去掉不再使用的旧图；外部手改/添加内容拒绝覆盖；哈希元数据在内部归档，替换支持失败回滚。备份恢复到新目录后再次导出通过测试。旧任务需先新版重新导出一次。
8. 更新文章导出/打开按钮与内嵌公众号后台入口，生成 v1.1.0 Windows 安装包和免安装 ZIP。
