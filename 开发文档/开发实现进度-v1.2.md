# v1.2：自动准备文章与配图

本轮按用户确认实现：拟题、大纲、最终标题和配图计划自动选定，完成后统一审阅。TapNow 生图及公众号发布仍由用户在程序内网页工作台操作。

## 已实现

| 需求 | 实现与使用入口 |
| --- | --- |
| 自动文章工作流 | 新建文章选择“自动准备”；AI 拟题可留空，根据当前栏目前五篇正文与全部标题规划；手工标题/大纲标题继续保留 |
| 统一审阅 | 自动选择四个编辑节点并记录决策；最终点击“已统一审阅，复检并导出”；修改正文、标题或所选图片后原确认失效 |
| 配图提示词 | 按正文、图位、主题色及风格参考自动策划；每个生图图位可打开编辑器修改、重拟和保存；截图图位不使用生图提示词 |
| ICE Loop 品牌风格 | 公众号档案新增“生图视觉规范”；资源箱可导入7张已确认原图副本；重复导入去重，其他公众号保留独立规范 |
| 通用风格参考 | 任意资源可标记为当前公众号风格参考，最多8张；策划读取说明、构图、识图记录和实测配色 |
| DeepSeek 识图 | 独立视觉模型配置、真实图片输入及测试入口；按官方当前能力选择支持图片输入的模型，与写作模型独立 |
| 自动运行截图 | 桌面后台渲染真实运行记录、截图归档；保护已有图片与人工拒绝的截图，失败显示原因；无真实记录不伪造 |
| 自动代码执行 | Docker 模式可准备缺失输入并授权隔离运行；默认本机模式继续先审阅代码 |
| 手动交付 | 程序内 TapNow 中国站 `https://app.tapnow.media/home` 生图、导入结果、统一审阅；导出仍为文本 MD 与图片两个目录，再进入微信网页后台手动发布 |

- 本轮验收记录：`ice-loop-agent/docs/v1.2-验收结果.json`
