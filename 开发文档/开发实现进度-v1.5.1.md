# v1.5.1 品牌配图与网页空间

本轮直接对照用户提供的 AI/001 配图提示词与 ICE Loop 原始视觉资产，完善配图提示词及内置网页操作空间。

| 部分 | 实现 |
|---|---|
| 封面 | Edit image 模板编辑；按PY/JV/AI/WK选择对应03–06封面；只修改标题和期号，保留原图画布、字体、位置、背景、副标题及字标 |
| 身份 | 01头像为叠排身份核对参考，02透明横向字标保留为独立原始资产；不混合两种字标形态、不重绘双O交织 |
| 正文图 | 七要素英文一段式；明确比例、颜色、逐字文字、元素位置、层级、箭头方向和禁止项 |
| 对话 | 与工作流共用规则及具体范例；新生成且明确为封面的首条提示词增加确定性模板保护；手工提示词及正文图不因此改写 |
| 参考图 | 新增按图位读取上传顺序的API，配图提示词编辑器显示文件名、角色和已导入参考图预览 |
| 网页 | 默认收起说明；展开/收起偏好持久化；扩大网页/恢复布局只改变区域尺寸，不重建网页或清除会话 |

实现主要位于 `ice_agent/genprompt.py`、`image_prompts.py`、`creative_chat.py`、`workspace_assets.py`、`desktop/renderer/browser.js` / `.css`、`visual.js` / `.css`；桌面和后端允许列表均接入 `prompts.references`。新增功能保留已有的公众号隔离、图位/正文哈希核对、人工修改保护和图片选择。

旧文章及其已保存提示词不会批量迁移或覆盖。需要使用新规则时，在配图图位重拟、审阅并保存，或者在创作对话的配图模式重拟。

原生测试还定位并修复 `Store.__init__` 每次读连接都写 `PRAGMA user_version=9` 的问题。已有库仅打开连接就产生写入，后台流式生成持有写事务时会造成 `database is locked`。现在版本标记仅在初始化/迁移时写，保留原schema版本和真实事务语义；“读连接不改变data_version”“另一连接持有写事务时可打开已有库读连接”两项回归先重现失败，再修复通过。初次界面接口漏接与数据库锁失败日志保留，最终以重建引擎后的验收为准。

完整说明、可复制提示词范例、实际测试日志及安装包核对结果分别位于 `ice-loop-agent/docs/v1.5.1-升级说明.md`、`v1.5.1-提示词示例.md`、`v1.5.1-验收结果.json`。原生测试使用G盘隔离数据、离线模型和本地网页夹具，不调用真实付费模型、生图、发布或运行用户当前安装的升级向导。
