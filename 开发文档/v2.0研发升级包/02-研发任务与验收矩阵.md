# v2.0 研发任务与验收矩阵

日期：2026-10-07。基线 v1.5.3。**以下100项是待实施任务，不是已完成清单。**

## 执行规则

- M0–M9 共10阶段、每阶段10任务。所有任务均属于v2.0主线；P0/P1仅代表先后和故障阻断程度。
- 默认按依赖顺序执行；阶段最后一项是集成出口。不能只做UI/只做P0后宣称完成。
- 每项状态、当前实现路径、实际验收命令、证据文件、未解决限制写入项目 `docs/v2.0/IMPLEMENTATION_STATUS.md`。
- “通过”必须来自实际执行；已存档的v1.5.3结果只作参考。本次报告没有完成这些任务。
- 账号范围、原稿hash、v1.5.3进程/输入隔离和原图查看是全阶段共同不变量。
- 表中工具/模型/schema为目标设计，编码前M0确认与现有对象映射。凡能复用领域服务，不重复新建一套。
- 权限不足、无法进行真实云端调用等应标明阻塞/未授权；离线fixture不能充当真实TapNow生图或发布。
