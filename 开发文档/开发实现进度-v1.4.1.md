# v1.4.1 会话、任务与真实初稿修复

用户反馈会话无法删除、任务不能归档/删除、初稿无法生成。本轮只读实际 v1.4.0 运行记录，确认三次 DeepSeek 回复完整结束，却因严格 JSON 解析失败没有候选稿。未修改用户真实数据或付费请求。

## 实现

- 创作专用完整 Markdown、围栏、常见 JSON 包装恢复，保留全文。系统层给出结构样例，截断结果仍拒绝；代码块 # 注释不算文章标题。
- 会话 `chat.delete`、`chat.restore` 与 `chat.list deleted:true` 回收站；归档仍 `chat.update archived:true`。已存稿和审批保留。
- 任务 `jobs.archive/delete/restore`，列表 visibility 筛选，隐藏任务操作与账号隔离检查。恢复暂停、不自动运行；当前执行结束前禁止恢复。
- 排队暂停、迟到节点覆盖状态、多段代码取消等修复。隐藏任务无法从创作审批或配图入口继续修改。
- 会话/任务管理窗口与删除确认，未存修改有明确提示；快速回复后的按钮刷新、新建会话接续初稿、恢复只读、切换时旧工具栏以及公众号旧响应竞争保护。
