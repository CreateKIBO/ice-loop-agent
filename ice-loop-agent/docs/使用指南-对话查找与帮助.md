# 对话查找、使用帮助与诊断

适用：2026-10-20源码工作台。本说明不代表已生成新的安装包。

## 对话窗口内查找

在会话标题右侧点击「窗口内查找」，输入关键字。范围仅为当前已加载的消息窗口（通常最多40条），不是所有历史文章或整个会话。命中数按消息计，同一条内出现多次也只算一条。

输入后自动定位第一条命中；「上一处」「下一处」循环定位，Enter下一条，Shift+Enter上一条。中文输入法组词时Enter只用于候选确认。点击「清除」清空查找但保留查找框；Esc或「关闭」退出并返回查找按钮。

查找期间固定正在阅读的消息窗口，新回复会保留在实时末尾，不抢走定位。点击「回到最新」重新查看最新消息。更早内容需先用历史翻页载入后再查找；不存在已执行全历史搜索的暗示。

## 使用帮助

左栏「使用帮助」和Ctrl+K命令面板均可打开。帮助包括使用流程、快捷键和排障三个分类；搜索仅作用于当前分类，可切换分类继续找。标签页支持方向键选择，Tab进入内容。

使用流程覆盖账号与历史、模型及预算、选题、初稿、修改审阅、配图/TapNow、导出发布、备份恢复。阅读帮助不会发送模型请求、执行代码或自动发布。内嵌网页打开时，帮助显示期间网页暂时让位，关闭后恢复同一个网页视图。

模型调用预算有不同范围：普通文章与补图任务的设置范围为1–100次；只有创作会话允许0表示不限制，未配置会话预算时默认24次。全局默认值和已有任务快照不同，不能只改默认值就假定旧任务上限也变了。

## 错误与诊断

候选保存或提交失败时，会显示下一步说明和可展开的诊断。超时、输入超限、模型能力不匹配等有独立说明；错误码和适当长度的消息保留供排查，常见凭据字段会被遮盖。

脱敏不是对任意服务端文本的绝对保证，分享前仍应检查是否含个人信息、文章内容或其他敏感数据。网络错误也不证明远端未处理；状态不明时先确认结果，避免重复提交。停止前已被模型处理的部分仍可能产生费用。
