# v1.1.1 安装升级修复

2026-10-03。此版修复运行中的 Agent 占用程序文件导致的升级问题，保留 v1.1 的内嵌 TapNow、微信公众号后台和两文件夹发布包。

## 怎样安装

先保存正在编辑的内容，再运行 `release/ICE-Loop-Studio-1.1.1-Setup.exe`。不需要手动结束 Agent。

安装器沿用已有安装位置，点击安装后会自动：

1. 确认当前 Windows 会话中本产品的主进程、后台引擎和关联子进程。
2. 请求正常关闭，等待最多 8 秒；仍未退出时结束确认身份的残留进程，再检查退出状态。
3. 将旧安装目录内的工作区暂存到同一磁盘、安装目录外，避免旧卸载器清理程序文件时连带删除数据。
4. 替换程序文件，将工作区放回原路径，然后完成安装。

安装载荷改为 ZIP 直接解压，并检查解压结果；不再使用临时解压后调用 Windows Shell CopyFiles 的复制流程。本项目没有使用差分自动更新，这次关闭差分载荷以匹配直接 ZIP 解压。早期静默安装测试曾超时，测试器给包含空格的 `/D=` 参数加引号不符合 [NSIS 官方参数要求](https://nsis.sourceforge.io/Docs/Chapter3.html)，已修正测试调用；不把这次测试超时直接认定为用户安装失败的根因。

源码版通过绝对项目目录与 `ice-loop-studio` 包标识识别；安装版通过完整可执行路径和本产品资源目录识别。不会按 `python.exe` 或 `electron.exe` 名字批量结束无关程序。不可确认身份或关闭失败时，在替换文件前停止并显示错误；若 Agent 以管理员身份运行，安装器也需相同权限。

本次确认你的安装位置是 `E:\Ice loop\ICE Loop Studio`，工作区位于该目录内。升级会保持原工作区路径，因此沿用原任务和文章数据，无需再导入一次。模型连接或网页登录是否保持仍以你启动后看到的实际状态为准。

## 工作数据保护

暂存采用同卷目录重命名，保留整个工作区和原有路径关系，不重写数据库、正文、配图或凭据。每次操作先核验绝对路径范围；目录已存在、跨卷或无法安全处理时，停止而不覆盖。

暂存目录位于旧安装目录旁的 `.ice-install-recovery/<编号>/`，恢复完成后留下操作清单。安装中断时退出钩子也会尝试放回原路径。若机器断电或安装器被强制结束，保留该恢复目录；其中 `manifest.json` 记录原路径和暂存路径，数据不会被当作临时文件自动删除。

更新包的程序版本是 1.1.1；本次未修改文章引擎业务代码，沿用已验收的 v1.1 引擎。Windows 安装器和 ZIP 仍为本地未签名构建。
