# ICE Loop Studio v2.0 用户手册（按 100 项矩阵交付）

适用版本：v2.0（源码包内 desktop/package.json 版本以实际构建为准）。
本手册只描述已实现并可验收的功能；真实云端生图/发布属于手工操作，程序不代替用户执行。

## 1. 启动与工作台

- 安装后启动进入工作台。菜单或 `--new-ui` 启动参数可切换新版三栏工作台（导航/对话/文章任务）；
  旧界面在同一安装内继续可用，未保存输入不会因切换丢失（对象级脏状态保护）。
- 左栏：公众号切换（切换即整体清空缓存防串号）、最近会话、知识检索面板。
- 中栏：对话（讨论/初稿/改稿/配图四模式，中文输入法组词期间回车不误发）。
- 右栏：知识检索、制作任务列表（含"正在停止"态与归档过滤）。
- `Ctrl+K` 打开命令面板；编辑器内可切换富文本/源模式（源模式加载失败自动回退纯文本，输入保留）。

## 2. 统一文章编辑器

- 从右栏制作任务（已完成）点"编辑正文"进入编辑器；Tiptap 富文本 + CodeMirror 源模式。
- 保存分两层：**工作草稿**（输入约 0.8 秒自动保存，重开提示恢复）与**保存新版本**
  （显式按钮，产生不可变版本；若别处已改会提示冲突且本地内容不丢）。
- 选段修改提案逐项展示前后对比，可接受/拒绝/改后接受；人工改过的段落不会被旧提案覆盖，
  其余段落可安全重放（结果状态"部分应用"）。
- 版本历史可恢复到任意旧版（旧版内容生成新版本，不删历史）；审批基线过期会显示横幅。
- "工作流状态图"折叠面板显示 14 节点实时状态（只读投影）。

## 3. 知识检索与选题

- 右栏"知识检索"：输入 ≥3 字走全文索引，1–2 字自动降级精确子串；结果可一键"引用"进入对话上下文。
- "导入文档"支持 .md/.txt/.docx（10MB 内；同内容自动去重；PDF 需先转文本）。
- 重复选题检查：对话/选题流程给出命中原因（同名/包含/检索相似），允许坚持选题。
- 排期大纲导入：单栏目最多 1000 条，栏目数量无上限（已验证 12 栏目 × 200 题）。

## 4. 编辑 Agent（对话驱动）

- 对话中模型可发起受限工具（检索旧文、读版本、提提案、建任务、提问等 18 项）；
  行动卡显示每次调用的工具名/状态/耗时。模型不能执行命令行、不能批准执行、不能发布。
- 提出的澄清问题持久保存，重开会话可回答续接；已回答问题不被覆盖。
- 同一组调用重复出现会自动停止（不空转烧预算）；同工具同参数连续失败 2 次熔断。
- 会话预算：`max_chat_calls`（默认 24）按会话计数，超限在入口拦截并提示调整。

## 5. 配图与发布（手工边界）

- 图位绑定：运行证据绑定到图位时校验源码 hash；预期错误素材需显式批准。
- 提示词候选带七要素检查（缺项/期号残留/真实输出被生图替代会提示）；用户编辑生成新版本，不覆盖旧版。
- TapNow 生图与公众号发布始终手工完成；下载的图片先进待归档箱（校验文件头），确认图位后才绑定。
- 导出：`articles.export_bundle` 产出 **文本/ + 图片/** 两目录与 manifest.json（含全部文件 hash）。
  已存在目录会拒绝（不无声覆盖）；"发布就绪"模式缺图/留占位符/运行引用未解析时阻断。
- 导出 ≠ 发布：发布后请在历史页登记日期与链接，下一期期号按真实发布进度建议。

## 6. 预算、备份与恢复

- 制作任务按次数预算（任务级），创作会话按 `max_chat_calls` 计数；金额估算需用户自填价格表，
  未填则显示"金额未知"。
- 备份：运行中任务会阻止备份；备份包含数据库一致快照、运行证据并逐一校验 hash。
- 恢复：只能恢复到全新目录；路径自动重映射；恢复后任务置为暂停待确认。
- 数据库迁移自动进行并留 schema_migrations 审计；较新版本数据库拒绝被旧程序打开。

## 7. 故障与恢复入口

- 停止按钮：本地立即标记"正在停止"；远端请求可能仍产生费用（如实提示，不假装退款）。
- 导出/保存失败均保留输入原位重试；断线后事件按游标补取，不重复应用。
- 诊断：健康摘要（版本/schema/队列/错误类别/磁盘分类）、临时残留清单（只列不删，清理需确认）。
