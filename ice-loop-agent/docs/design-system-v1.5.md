# ICE Loop Studio v1.5 界面规则

适用于独立 Windows 创作工作台。参考 LibreChat 输出面板、Open WebUI 文档旁对话和快捷搜索；具体来源见 v1.5-research.md。ui-ux-pro-max 检索建议强调清晰扫描和一致组件；保留项目已有纸面色、品牌字体和无阴影约束，不采用通用 SaaS 落地页布局。

## 视觉

- 暖白 #F3F2ED、墨黑 #15191F、默认信号蓝 #2448DB；公众号配置仍提供主要交互色变量。
- 系统中文无衬线用于导航与控件，衬线用于文章标题，等宽用于代码。无需联网加载字体。
- 控件 30–39px、常规按钮 36px；正文 15px/1.95，专注稿件 16px；元数据保持足够对比。
- 容器 8–12px 圆角，细边框区分区域，不使用大阴影、渐变或卡片悬停缩放。
- 侧栏头和连接状态固定，中段独立滚动；折叠侧栏保留图标入口。最近草稿/会话可以折叠。

## 操作与反馈

- 对话、保存初稿、审批、配图与导出有真实状态引导；候选稿不会自行采用。
- Ctrl K 搜索当前公众号的本地会话、草稿、任务及页面，不调用模型。上下键选择，Enter 打开，Esc 关闭。
- 输入按公众号与会话保留；只保存未发送文字，不保存 API Key 或附加文件内容。最多 30 个输入记录，有效 30 天。
- 快捷指令仅补到输入框，由用户修改并发送。文章引用和选中文段可清除。
- 接收内容时保留未变化的消息节点、展开状态和阅读位置。显式“回到最新”与首次发送后的追踪帮助阅读。
- 草稿预览显示字符数、保存状态、下一步；可进入全宽专注阅读并以 Esc 返回。

## 开源组件与动效

Shoelace 2.20.1 提供分栏和页签，Lucide 0.468.0 提供统一线性图标；新增 Motion 14.0.0 的 JavaScript animate/stagger。由 esbuild 打包，资源与 MIT 许可证随发行包保留，运行不访问 CDN。

短动效约 200–230ms，列表最多前六项 stagger 35ms；运行标记转动 1.4 秒一圈，预览骨架轻微透明度循环 1.8 秒。阶段变化才重新入场，同阶段只更新字符数和用时。卸载/隐藏节点取消自身控制器，不保留中间透明度或 transform。

系统减少动效始终生效，程序亦可选择减少动效；循环和短动画均停止，真实状态和用时继续显示。界面密度可选舒适/紧凑，文章阅读字号不因密度设置缩小。

## 边界

保留 Markdown 保存、版本对比、审批哈希和多公众号隔离。TapNow 和公众号后台仍在内置 Chromium 中由用户操作；不自动付费生图或发布。
