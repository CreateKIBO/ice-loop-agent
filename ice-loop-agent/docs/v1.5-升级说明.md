# v1.5 创作体验升级说明

本轮将独立桌面程序升级为更适合持续写作的工作台。吸收 LibreChat 独立输出面板、Open WebUI 文档旁对话和快捷搜索的交互思路，保留本项目的 Markdown、人工审批与多公众号隔离。官方来源与取舍见 [调研记录](v1.5-research.md)，视觉和动效规范见 [设计规则](design-system-v1.5.md)。

## 界面与开源动效

保留暖白纸面、墨黑文字和默认信号蓝；统一导航图标、字号、按钮和表单，弱化装饰，让文章正文更适合阅读。侧栏头和连接状态固定，中段独立滚动；“最近草稿”“最近会话”可折叠，顶栏左侧可以收起整条侧栏。

采用真正的 Motion 14.0.0（MIT）JavaScript 库，配合现有 Shoelace 分栏/页签和 Lucide 图标。动效库及其许可证随程序打包，运行不依赖 CDN。页面、弹窗、列表、消息和生成状态使用 Motion；同一生成阶段只更新字符数/用时，不反复入场。

顶栏“显示偏好”可选择舒适/紧凑密度、开启或减少动效。系统的减少动效始终生效；关闭动效仍保留阶段、实际用时和字符数。不会用虚构百分比模拟模型工作。

## 更顺畅的创作过程

1. 在“公众号与品牌”建立档案、导入历史文章，在“模型与设置”配置模型。已有工作区继续读取原数据。
2. 新建创作对话，选择栏目后讨论选题或点击“生成初稿”。没有会话时直接输入并发送，会先让你选择会话/栏目，确认后衔接原消息；取消仍保留文字。
3. 初稿在右侧展开。状态条显示字符数、保存情况和下一步；“专注阅读”放大文稿，Esc 返回。可以手动修改、选择文段改稿，或比较候选版本。
4. 选择“保存初稿”后显示在侧栏和草稿箱；准备好后“同步至文章审批”，确认采用后再继续配图与导出。顶部流程提示根据真实状态变化，不自动代你批准。
5. 配图对话生成提示词；可截图内容沿用既有制作任务。TapNow 与公众号后台继续在内置浏览器里使用，由你生图、排版和发布。

输入按“公众号 + 会话”自动保留在本机，切换页面或会话后可恢复。仅保留未发送文字，不复制 Key 或附加文档；最多 30 个输入记录、30 天有效。发送返回时若你已开始输入下一句话，只清除实际已发送的内容。快捷指令只追加到输入框，发送前可以修改。

旧消息按身份和内容保留节点，接收新回复时不打断旧消息的展开、文字选择与阅读位置。“回到最新”帮助你返回新内容；文章引用和选中文段可以直接取消。

## 找到内容与内置网页

Ctrl K 打开快捷搜索，输入标题关键词、栏目或记录 ID，查找当前公众号的会话、草稿、制作任务及页面。上下键选择、Enter 打开、Esc 关闭。搜索读取本机记录，不调用模型；归档/删除记录仍通过原管理窗口查找和恢复。

快速打开内容后再次搜索会等导航完成后打开；关闭后迅速重开不会被旧关闭事件清空。切换公众号会清除旧搜索结果，防止串号。

在内置网页内按 Ctrl K 同样能打开工作台搜索。搜索/显示偏好弹窗打开时，原生网页暂时隐藏；关闭后恢复原网页及登录会话。侧栏收起和小窗口尺寸变化时，网页区域自适应对齐。TapNow 入口仍是 https://app.tapnow.media/home。

## 升级与验收

安装前保存正在编辑的内容。安装器沿用此前的自动停止旧程序逻辑；免安装 ZIP 适合解压到独立的非 C 盘目录。工作区位置按原配置读取，程序包不内置个人文章、登录信息或 API Key。

本轮实际测试与最终安装包信息记录在 [v1.5 验收结果](v1.5-验收结果.json)。测试使用隔离工作区、离线模型和浏览器夹具；公开站点仅浏览，不登录、不生图、不发布。安装器载荷与源码会分别核对；本轮不替你执行安装向导。

最终已通过 60 项 Node 测试，源码版与打包版各 85 项创作桌面检查、25 项内置浏览器检查，运行时未发现意外 JavaScript 错误。安装器、ZIP 和内置引擎的一致性核对完成。查看 [保存初稿后的界面](screenshots/v1.5/chat-saved-sidebar.png)、[快捷搜索](screenshots/v1.5/v1.5-command-search.png) 和 [显示偏好](screenshots/v1.5/v1.5-display-preferences.png)。
