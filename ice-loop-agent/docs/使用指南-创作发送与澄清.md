# 创作发送、重试与澄清

## 正常创作

在创作会话下选择讨论、初稿、改稿或配图，输入要求后发送。等待状态反映实际请求；未确认上一条发送前，新输入会保留，但不会额外发起另一条。中文输入法选词确认不应发送消息。

生成失败的消息下可点「重试此回复」。这会保留原失败记录，使用原需求、引用及模型配置开始一次新的生成，可能产生新的模型费用。初稿完成后先显示候选卡；「保存为草稿」才会进入共享草稿箱，保存不等于文章审批通过。

## 发送结果未确认

网络中断或进程短暂失去响应时，程序可能已经受理请求，界面不能仅凭超时判断发送失败。

- 「核对并继续发送」：如果已经受理则取回原结果，不重复生成；如果之前未受理则继续原请求。
- 「取消这次请求」：尚未受理时禁止这条请求以后继续生成；已受理且仍在生成时停止对应回复，保留历史。远端已经处理的部分仍可能计费。
- 重新打开会话只会自动查询回执，不会自动重发或重新调用模型。

核对期间修改的输入不会被旧回执覆盖。请求记录有明确容量上限；存储失败时会提示只存在当前进程内，不宜直接关闭。明确的预算拒绝会保留输入并提供预算设置入口。

## 补充关键信息

当模型提出澄清问题时，消息下会显示「确认后继续创作」。可选建议后继续修改，也可自行填写。回答全部问题后点「确认回答并继续生成」，原需求、用户选择的模型和知识引用会一起保留。

「本次知识引文」默认沿用原引用。若来源已经更新，可在右侧知识检索重新选择，再改为「改用当前选中的引用」；也可明确选择「本次不使用知识引文」。选择改用但尚未选中资料时不能提交。资料过期会保留问题与回答，不能悄悄忽略引用继续写作。

切换会话后未提交回答会尝试从本地恢复。回答在本地有界保存，不能替代正式草稿备份；不能保存时界面会明确提示。已回答的问题显示当时提交的内容，过往问题不能在旧卡片上再次提交。

## 动效和可访问性

加载活动条用于说明实际等待，不表示虚构的完成百分比。卡片短淡入，按钮等待期间保持布局稳定；系统开启「减少动态效果」后会停用不必要的动画。错误和结果可通过屏幕阅读器状态区读取，时间跳动不会每秒播报。

## 界面打磨要点（2026-10-25）

- **复制的真实反馈**：所有「复制」按钮成功时文字短暂变为"已复制"；系统剪贴板不可用时会明确提示"复制失败"并给出可手动选择的内容，不会假装复制成功。
- **候选初稿卡**：除「展开全文」「保存为草稿」「提交审阅」外，新增「复制全文」——把整篇初稿带走继续加工；保存草稿仍不等于采纳或发布。
- **提示词未保存提醒**：配图工作台修改提示词后，操作行出现"未保存修改"徽章；「放弃修改」可一键恢复到已保存版本，徽章随之消失。
- **下载文件完整路径**：下载待归档条目新增「复制完整路径」，列表中长路径视觉省略但原值可完整复制（文件摘要为 SHA-256，用于校验文件内容，不代表图片视觉效果）。
- **文章目录与修改导航**：编辑器「文章目录」来自正文真实标题（代码块内的 # 行不会入目录），点击跳转；修改提案面板提供上一处/下一处与跳转下拉。

## 示例公众号旅程（虚构演示，不写入任何真实账号）

以虚构公众号「纸间观察 · 栏目 OBS」为例：

1. **准备**：欢迎页三步清单确认公众号与栏目（1 个栏目即够用）、接入模型（保存 Key 后测试一次连接；显示"已就绪"才代表测试通过）、可选关联历史文章。
2. **选题**：打开「选题与排期」，系统按已发布期号推导默认下一期；也可粘贴大纲「识别并预览」——预览头部显示条数/栏目/期号范围/与已存冲突，逐行问题（标题空、期号非法、同栏目同期号重复）就地标出；覆盖已有期题需逐条"旧→新"确认。
3. **讨论**：「确认并带入对话」把期号/标题/要点带入会话（确认前不调用模型）；先讨论或直接出初稿。
4. **澄清**：模型需要补充信息时出现澄清卡：点建议或自己写都行，选了还能改；引用策略按需沿用/改用/移除。
5. **初稿**：候选卡「展开全文」阅读→「复制全文」或「保存为草稿」→「提交审阅」（保存≠采纳）。
6. **修改**：编辑器内打开修改提案，逐项对比后接受/拒绝；「文章目录」快速跳转章节。
7. **配图**：任务卡「编辑正文」→「准备配图」：总览看每个图位状态，「下一个待处理图位」直达；「制作清单」一键生成按图号整理的交接材料（含已保存提示词与参考图顺序）。
8. **生图**：复制提示词→「打开内嵌 TapNow」→按顺序上传参考图并生成→图片出现在「下载待归档」→选择文章与图位→「绑定并采纳」（目标已有图片会提示替换）。
9. **审批与导出**：交付审阅显示六类检查摘要与"只看未完成"；确认后导出发布就绪包（缺项时导出草稿包并逐条列出待处理项）。

## 常见问题

- **提示"确认已完成，状态读取失败"**：写操作（确认/保存/绑定）已成功，只是读取最新状态失败；点"重新读取"即可，不要重复执行写操作。
- **"已保存草稿，列表刷新失败"**：草稿已保存，刷新列表失败单独提示；重试刷新不会重复保存。
- **回执未确认/超时**：超时不等于失败；重新打开页面会只读核对回执，「继续原请求」沿用原请求 ID，不会重复生成。
- **引用过期**：澄清或继续时原知识引文已变化会被拒绝，需明确选择沿用/替换/移除后才能继续。
- **图片显示"待配图"但已有候选**：候选存在不等于已采纳；在配图工作台审阅并采纳后才计入"已有有效图片"。
- **剪贴板不可用**：复制按钮会提示失败原因；提示词/路径可从对应输入框或详情中手动选择复制。
- **导出按钮不可用**：发布就绪包需先通过交付审阅且无强制阻塞项；草稿包随时可导出并附待处理清单。
- **内嵌网页需登录**：TapNow/公众号后台在内嵌浏览器中由你自行登录；应用不会替你登录、生图或发布。

## 候选稿阅读与复制（2026-10-25 增补）

- 候选卡展开后可在「阅读预览」与「Markdown 原文」之间切换：阅读预览按公众号常用的标题/列表/表格/引用/代码排版展示（这是阅读视图，不是公众号最终发布排版）；原文视图保留完整 Markdown 源文。
- 「原文 N 字符」统计的是 Markdown 源字符数，不是 Token、字数或费用。
- 「复制全文」始终复制完整候选正文（原文），与当前查看视图无关。
- 阅读方式与展开状态只保存在当前界面，切换会话或刷新后回到默认折叠，不影响草稿保存与提交审阅。

## 任务列表视图复位（2026-10-25 增补）

- 任务列表右上「恢复默认视图」把当前公众号的**显示偏好**恢复默认：状态筛选（含"需要我处理"）、紧凑视图、搜索词、含归档开关。它只重置这些显示项，不清除任何文章、草稿、发送记录或另一个公众号的偏好。
- 当前已是默认视图时该按钮禁用；恢复成功后会在列表上方出现简短确认。

## 提示词参考图与字符统计（2026-10-25 增补）

- 配图工作台的「品牌参考图」默认折叠；展开后显示上传顺序与每张图的完整文件名，可单独复制文件名。折叠时不保留缩略图（图片资源按需重新读取）。
- 提示词编辑框下方实时显示「N / 30000 字符」与未保存状态；复制提示词取当前编辑框的完整文本。

## 候选对照阅读（2026-10-25 增补）

- 在会话候选区点「加入对照」选择**当前页**的两份候选（标题相同也可，按正文区分）；只选一份时会提示再选一份，选第三份会被明确拒绝。点「打开对照」并排阅读。
- 对照面板中每份可独立：切换「阅读预览 / Markdown 原文」、查看本栏目录（真实标题，代码块里的 # 不算）、点「回到开头」（向下阅读后可用）、点「复制此份原文」（复制的是本份完整正文）。阅读预览是阅读排版，不等于公众号后台最终排版。
- 对照是只读的：不保存、不采纳、不提交；翻到更早/更近的候选页或切换会话后，对照选择自动清空（需要时重新选择）。
- 配图工作台参考区：折叠标题显示当前图位参考数量；展开后按图片编号顺序上传（图片 1 先传），每条可复制完整文件名，也可一键「复制文件名清单」——清单只是文字，不包含图片文件本身。
