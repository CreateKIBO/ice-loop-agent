## 本轮已修复

### 1. 初稿保存与草稿正文

`ChatPane.tsx` 候选卡原先调用 `chat.candidate_save`，它修改候选而不持久化到草稿库；因此“已保存草稿”状态不出现，提交按钮也不能正常启用。

改为 `chat.save_draft`，携带真实 candidate_id/content_hash，成功后重取候选并使本账号草稿查询失效刷新。已提交候选显示提交状态，保存和批准继续分开。

`LeftNav.tsx` 草稿列表只有摘要字段，弹窗原先没有正文。改为打开时调用 `drafts.get` 获取本账号正文，显示加载/错误状态。原生验证确认草稿数增加且弹窗出现正文标记。

### 2. 会话归档、回收站与导航保存失败

原 UI 请求 `chat.list {}`，后端返回活跃会话，再在前端过滤归档，结果永远空。现在查询携带 archived/deleted 参数；添加会话回收站、还原，以及各视图空态。

原 `flushAllDirty` 吞掉错误并返回失败键，多处调用忽略返回值，切页/切账号继续执行，可能丢失 debounce 窗口内内容。本轮抽出 `dirtyFlush.ts`，失败抛出异常、保留编辑状态，重试成功清掉失败信息；旧 effect cleanup 不移除后来注册的 flush。

会话切换、新建、归档/删除、任务操作、进入正文编辑、命令面板跳转、账号切换等待恢复写盘；账号切换不再在 finally 无条件 reload。失败时显示错误并取消导航。任务“彻底删除”改为准确的“移入回收站”文字。

这里修复的是已有恢复写盘的失败处理。空全文、在途保存继续编辑、关闭窗口与正式版本竞争等完整编辑状态机仍属于后续任务，不能宣称全部防丢覆盖。

### 3. 导出目录与主进程授权

系统 openDirectory 返回已存在目录，Python 导出拒绝覆盖现存目录，原界面正常选择后也会失败。现在选父目录后主进程签发短期路径授权，返回全新子目录；导出请求必须命中本桌面会话授权，成功后消耗，账号切换/配置导入后清除。

新增 `export-approval.cjs` 并加入打包文件；Python继续检查绝对路径、非C盘、链接与所有权，清理仅限自己创建且身份匹配的 staging。此方案是主进程内存 grant，不是独立的后端签名 token 协议。

编辑器有未保存修改时阻止导出旧正式正文；目录选择取消/抛错后正确恢复按钮状态。

验证覆盖：新子目录不创建任何文件、任意父目录/路径穿越未授权拒绝、过期/使用后拒绝、账号清理和打包模块包含。系统文件对话框到真实 ready 包的完整原生点击链尚需下一轮补齐。

### 4. 发布就绪校验与运行证据

修复两个明确放行漏洞：

- helper 在计算占位数前检查初始0值，且 allow_ready=True 时忽略 handler 的 blocking。现在真正的 image_slot 缺图/无效引用在写文件前拒绝；代码围栏内讲解占位文本不误判。
- handler 把 execution_plan 的 dict envelope 当列表使用，异常后 current_hashes 置空、code_ok 反而为真。现在读取 `plan['blocks']` 并用当前 integrated_md 构建计划，解析失败拒绝 ready。

运行证据核对 source/code_sha256、stdin_hash、expected_failure、verdict、exit_code、超时/输出上限及输出哈希；当前每个可执行块必须有匹配证据。旧代码、旧输入、改过的输出不能充当当前运行记录。

人审门改用既有 `delivery_hash` 与 state.delivery_review，缺少或过期拒绝；原比较把“title+body的JSON摘要”与“body文本摘要”比较，并且缺审阅记录可放行，均不正确。规则使用实际 cfg.profile，避免忽略自定义规则。

新 UI 尚缺完整的最终交付确认入口，故有些文章现在会正确提示未统一审阅。下一轮需要补界面和确认契约，**不能再删后端检查以让导出按钮通过**。

### 5. 模型最终答复、迁移 dry-run、源码版本和重复测试

- 工具多轮反馈后更新最后自然语言 reply，避免模型已经完成分析而用户仍看到首轮工具 envelope。加强已有测试，断言助手实际显示最终答复。
- dry-run 原先逐迁移回滚，前一迁移创建的表消失，后一依赖迁移失败；失败路径还可能残留跟踪表。改为 SQLite 内存备份执行完整迁移链，原连接无写入；加依赖链成功/故障无痕测试。
- Python 源码版本对齐桌面 beta.1；没有重编冻结引擎。
- 测试基类通过模块引用，消除8个相同 test ID 重复收集，保留子类继承测试。
