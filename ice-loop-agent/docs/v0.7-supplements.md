# v0.7：已有文章补图与逐张候选审核

日期：2026-10-02。对照开发设计文档 T18 与 T14，继续支持多公众号和用户手动 TapNow 流程。

## 开始使用

保存当前工作、关闭旧版窗口，再双击 `start-desktop.cmd`。本版沿用已有数据库，新增图片审核记录表，不清空文章、资源和公众号配置。

两种入口：

1. 创作工作台顶部「导入文章补图」，选择本地 Markdown 文件。
2. 「文章存稿」打开已有文章，再点「为这篇文章补图」。存稿目录在「公众号与品牌」设置。

只读取 UTF-8 / UTF-8 BOM 的 `.md` 文件，最多 400KB、100000 字符。首次导入保存原始字节快照、原文件 SHA256 与正文 SHA256；原文件不会写回。导出位置为本篇冻结的公众号输出目录中的 `补图候选/`。

## 图位计划

独立图片行 `![图注](地址)` 会建立图位；代码围栏内的图片示例不会被当作配图。原稿的 `图N：` 编号保留，其他图片按未占用编号分配，重复图号会提示先修改原稿。最多 32 个图位。

原有的相对本地图片仅在原稿目录范围内读取，复制成「待审核候选」，不会自动认定可用。缺图、远程地址和目录外图片保持待准备，不自动联网下载。

「编辑配图计划」可以修改用途、图注与 TapNow 提示词；也可以添加图位，选择标题之后、章节之前或文章结尾。已有原稿图片行的位置及图注文字保持原样，计划图注用于描述要求；新增图位使用你填写的图注。修改图位要求后取消当前选用，旧候选保留，需要重新审阅选用。

默认提示词由本篇公众号品牌与主题生成可编辑模板；补图任务没有调用语言模型，不把模板当作 AI 语义分析结果。截图图位不保存生图提示词。

## 准备和审阅图片

- **已有资源**：点「推荐已有资源」，预览后选用。推荐使用当前公众号资源的内容标注、用途、比例和配色。
- **手动 TapNow**：复制当前图位完整提示词，点「打开 TapNow」，在 `https://app.tapnow.media` 自行粘贴生成、下载，然后「导入并选用」。没有自动提交、下载或付费生图。
- **逐张审核**：候选列表点「预览与审核」。可以接受并选用，或填写原因后否决。否决当前选用图后恢复待准备；被否决图片不会出现在可采用下拉列表，也不能通过旧请求继续选用。
- **保留旧图**：否决不删除文件。原因和每次审核决定进入记录；重新审阅后可明确接受旧候选。审核绑定当前图位和候选版本，其他窗口修改后旧决定被拒绝。

「导入并选用」、截图归档并选用、资源推荐后的选用都是明确的用户采用动作；旧文件首次导入则需要独立审核。候选审核也可用于普通写作任务的配图页。

## 原稿代码的真实截图

进入「原稿代码与运行」→「审阅并执行示例」。识别最多 20 段 Python / Java 代码围栏，每次只执行一个片段：

1. 选择代码、填写逐行交互输入，预览实际源码和输入。
2. 勾选已检查并允许本次执行，再运行。修改输入后需要重新预览。
3. 记录真实 stdout、stderr、退出码、超时、代码/输出哈希与原稿来源。错误不会被改成成功输出；原稿声称的结果不会自动回填或核验。
4. 返回截图图位，点「Agent 截图」，选择本次记录。专用视图显示真实源码、输入与分区输出，再截图归档到图位和资源箱。

使用现有本机运行器与静态风险检测、20 秒超时；这不是完整 Docker / WSL 沙箱。原稿中的片段必须能够独立运行，依赖前段变量、第三方包或外部文件的示例可能报错，请先检查并选择合适的片段。该流程不自动运行文章全部代码，也不截任意 IDE 或外部网页。

同一代码和输入已经完成并保存记录后，再次提交复用该记录；改变输入需重新审阅执行。执行中的任务持有租约，不能同时编辑图位、审核图片或导出。恢复后的暂停补图任务可「继续任务」，仅回到图位工作区，不启动写作模型。

执行过的源码按 `code/supplement-N/文件名` 分段归档；两段 Java 都使用 `Main.java` 时也能分别保存，避免覆盖另一段示例。

## 另存候选与正文边界

「导出补图候选」生成 00、01、02、04 文件、`code/` 与 `images/`；有生图提示词时附 03 文件，另加 `05-补图变更记录.json`。只替换选用图片的地址，或在明确图位插入 Markdown 图片；既有标题、期号、文字、代码和原有图注不改写。原稿字节快照和导出正文分别保存，原有换行保持。

栏目期号只读取标题开头的 `PY / 007` 等编号或独立的 `栏目：PY / 007` 字段；无法识别时显示「栏目 / 期号未标注」，不根据正文里的上篇引用猜测，不推进发布进度。补图任务不会进入历史拟题上下文。

原文件被修改或移走后会提示，任务仍使用导入时已校验的快照；如需要新正文，请重新导入。导出文件的外部修改仍受 SHA256 冲突保护，程序不会覆盖人工修改。备份和新目录恢复包含原稿快照、图位、图片及审核说明。

配图全部有效时状态为「补图完成 · 正文待审核」。这不是事实审校、文章语义审稿或可发布结论。缺图也可以另存候选，保留待准备状态；最终仍需对照原稿检查文字、来源、图片位置，并在公众号后台排版与手机预览。
