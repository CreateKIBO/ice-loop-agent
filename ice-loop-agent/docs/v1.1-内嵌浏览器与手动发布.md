# v1.1 内嵌浏览器与手动发布

2026-10-02。此版按新的要求替换 v1.0 的外部 TapNow 浏览器入口，并增加默认的精简发布包。原有历史拟题、大纲、代码审阅、配图资源箱和备份流程继续使用。

## 在程序内部使用网站

左侧新增「网页工作台」，包含「TapNow 生图」和「微信公众号后台」两个网页页签。资源箱和文章图位上的 TapNow 按钮也进入这里，不再调用系统浏览器。

浏览器内核随桌面程序提供，无需安装或绑定 Chrome。实现使用 [Electron WebContentsView](https://www.electronjs.org/docs/latest/api/web-contents-view)，远端网页与本地工作台分别运行。

可以使用地址栏、前进、后退、刷新/停止和站点首页。网站需要的新窗口在程序内作为登录/网页子窗口打开；允许 HTTPS 跳转，禁止网页跳进本地文件、工作台协议或脚本地址。登录、扫码、验证码、生成及发布都由你在网页中操作。

每个公众号在每个站点都有自己的持久会话；切回其他工作台页面不会删除网页。切换公众号会关闭旧公众号的网页视图，再使用新公众号独立的会话，避免串号。未保存的网页表单需先在网站中保存。网页登录是否保持还受网站会话期限影响。

「清除当前站点登录」只清除当前公众号、当前站点的登录及缓存；其他站点和公众号保留。会话保存在非 C 盘工作区，备份和安装包不包含登录 Cookie。远端网页没有本地引擎、模型 Key 或文件读写接口。

## TapNow 配图流程

在文章图位复制完整提示词 → 打开内嵌 TapNow → 登录并粘贴提示词 → 手动生成 → 点击网站的下载按钮，选择保存位置 → 回到资源箱或文章图位「导入并选用」→ 审阅图片。

下载默认位置在当前工作区的 downloads 下，按公众号和站点区分；可以在保存窗口选择自己的目录。完成后工作台提示下载状态。图片下载不会自动变成已审核配图，仍需导入与选用。

此版不自动提交生图任务或消费额度。实际账号登录、生图、付款和公众号发布没有在开发测试中代你执行。

## 导出的内容

完成文章后点击「复检并导出发布包」，再点「打开发布包 · 文本/图片」。打开的目录结构固定为：

```text
001-文章标题/
├── 文本/
│   ├── 01-公众号正文.md
│   └── 02-发布信息.txt
└── 图片/
    ├── figure-01.png
    └── figure-02.png
```

正文为 UTF-8 纯文本 Markdown，没有 HTML 排版文件。代码保留为正文中的代码块；图片文件夹仅包含当前已经选用并验证的图片，不包含 README、源码或审核 JSON。正文图链使用 `../图片/文件名`，按图号对应；未就绪图位仍保留待配图说明，发布信息明确标出草稿状态。

发布包保存在公众号输出目录下的「发布包」子目录。原来的 00–04 文档、源码、证据和审核资料仍在另一份内部归档中；HTML 预览继续可用，不进入这个精简发布包。

重复导出会更新该任务的发布包并去掉已取消选用的旧图。外部手改正文、图片或增加文件时，会拒绝覆盖；先保留并移走/重命名这份修改后的包，再重新导出。发布包的校验元数据位于内部归档，发布包顶层仍只有两个文件夹。

旧任务需要先用新版「复检并导出」一次，再使用新的发布包按钮。安装版与源码版的数据迁移沿用 [v1.0 使用与验收](v1.0-使用与验收.md) 的备份恢复方法。

## 手动进入公众号后台发布

文章上的「内嵌公众号后台」或「网页工作台 → 微信公众号后台」打开 `https://mp.weixin.qq.com/`。自行扫码登录，创建图文，排版/粘贴正文并从图片文件夹上传配图，手机预览后确认发布。

Markdown 文件用于保存和排版，不代表微信后台直接接受 .md 上传并自动排版。可以继续使用自己的 Markdown 排版工具，再粘贴到图文编辑器；正文和图片分别取自这两个文件夹。
