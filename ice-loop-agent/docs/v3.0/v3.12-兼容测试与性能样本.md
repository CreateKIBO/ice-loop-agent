# v3.12 微信兼容测试稿、长文多图性能样本与基准（2026-11-08）

对应开发报告 §10 的第 1 项（真实微信交付）和第 3 项（长文多图性能）。这两项都必须在你的电脑和公众号上完成。这一轮把测试需要的样本、记录和测量工具做进应用，并按测量结果做了一处优化。

## 1. 微信兼容测试稿与逐项记录

文章首页新增 **微信兼容测试稿**：
- 选择要测的主题（可多选），每个主题生成一篇，系列为“兼容测试”。
- 测试稿共 18 组，每组前有【C01】…【C18】编号：段落缩进/对齐、三级标题、文字样式、颜色、字号、高亮、链接、列表、引用、代码、分隔线、普通图片、图注、2 列与 3 列多图、四种提示卡片、主题小标题、字间距/行距/段距。
- 图片是程序生成的色块图，用竖条数量表示序号，方便核对顺序与裁切；另有一张作封面。测试稿不含个人资料。

打开测试稿后，侧栏多一个 **兼容记录** 页签：
- 每项分 **粘贴后 / 后台保存后 / 手机预览** 三格，每格选“未验 / 保留 / 部分保留 / 丢失或错乱”。选了部分保留或丢失时可填说明。
- 顶部可填系统、缩放、公众号后台浏览器、手机机型和源码 HEAD。
- **复制 Markdown 记录**：生成与验收清单模板一致的表格和统计，并注明“未验”不能计为兼容。
- 记录只保存在这篇测试稿里，不影响其他文章。

接口：`documents.compat_create / compat_get / compat_record / compat_report`。

## 2. 长文多图性能固定样本

**样本**（`ice_agent/documents/perfsample.py`）：
- 约 1 万字中文正文，每约 1000 字一个小标题，配 30 张测试图。
- 图片尺寸与格式轮换：1080×720、1920×1080、750×1334、3000×2000、640×480、1242×2688、2400×800、1200×1200、800×600、4000×3000，JPEG 与 PNG 交替，30 张共约 26MB。
- 正文与图片由固定种子生成，可复现。每张图登记像素尺寸、格式、字节数和 sha256；编码字节在相同 Pillow 版本下一致。

**两种用法**

| 用法 | 测什么 | 怎么做 |
|---|---|---|
| 应用内 | 编辑器：打开到内容到达、打开到可输入、按键到下一帧绘制的输入响应（中位 / P95 / 最大）、自动保存往返、JS 堆 | 首页“性能样本”→ 打开 → 侧栏 **性能读数**。连续输入一段、滚动到底，然后“复制读数”。整进程峰值内存用任务管理器记录 |
| 命令行 | 引擎：生成样本、打开、小改保存、存版本、渲染预览、复制用 HTML、Markdown 投影、长图页面、导出图文包，以及进程峰值内存 | `python tools/perf-v3-documents.py --out perf.json`（Windows 上导出图文包需 `--workdir D:\perf` 这类非 C 盘目录） |

命令行工具只在新建的临时目录里运行，不碰任何个人工作区、公众号或模型配置，结束后删除临时目录（`--keep` 可保留）。读数只存在当前会话内存里，不上传、不写盘；开发者工具里也可以读 `window.__iceDocPerf`。

### 依据测量做的优化：预览缩略图缓存

在这里（Linux 云端容器，非参照机，仅作相对比较）对默认样本跑基准，瓶颈是 **每次刷新预览都把 30 张原图重新解码生成缩略图**：

| 操作（中位数） | 优化前 | 优化后 |
|---|---|---|
| 渲染预览（手机预览） | 915 ms | 首次 981 ms（填充缓存），之后 52 ms |
| 长图页面 | 894 ms | 51 ms |
| 导出图文包 | 1146 ms | 160 ms |
| 打开 / 小改保存 / 存版本 | 约 2 ms | 约 2 ms |
| 进程峰值 RSS | 229 MB | 199 MB |

- 预览缩略图按原图 sha256 缓存在运行目录 `cache/delivery-previews/`，上限 2000 张，超出时删最旧的。
- 大 JPEG 生成预览时先降采样解码，不完整解码原图。
- **复制到公众号**的那条路径保持 v3.0 的完整解码，没有改；原图、交付 hash 和导出包里的原图字节都不受影响。

这些数字不是 Windows 参照机结果，不能用来声称达到性能预算。

## 本地验收

1. 首页“微信兼容测试稿”→ 勾选 4 个主题 → 生成 4 篇。逐篇“复制到公众号”→ 后台粘贴 → 在“兼容记录”里填“粘贴后”；保存、重新打开后填“后台保存后”；手机预览后填“手机预览”。最后“复制 Markdown 记录”贴进验收记录。
2. 首页“性能样本”→ 打开 → 侧栏“性能读数”：连续输入 30 秒、滚动到底，复制读数，同时用任务管理器记录峰值内存。
3. 在参照机上运行 `python tools/perf-v3-documents.py --workdir D:\perf --out perf.json`，保存 JSON。
