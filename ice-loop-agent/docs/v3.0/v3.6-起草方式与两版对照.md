# v3.6 整篇生成：快速 / 引导式与两版对照（P1，2026-11-06）

对应开发报告 P1：“完善生成任务与快速/引导模式、变体对照；简单需求不展示全部内部节点。”

## 用法

首页 **AI 起草** 对话框里先选起草方式：

| 方式 | 行为 | 适合 |
|---|---|---|
| **快速生成**（默认） | 后台直接写完整初稿，不提问；信息不足时按合理默认补全。存为一篇“AI 初稿”，不抢焦点。 | 需求已经说清楚 |
| **引导式** | 打开助手会话，先用提问框问 2–4 个最影响成稿的问题（读者、篇幅、角度、必含要点，每题带选项），回答后再出初稿；满意后点“存为文章”。 | 只有大概方向 |

快速生成可勾选 **同时生成两个版本对照**：同一需求、不同切入角度，各存为一篇（列表里显示“AI 初稿·版本A / 版本B”），模型调用次数加倍。打开任一版，编辑器顶部有“对照另一版”，侧栏 **两版对照** 只读显示另一版全文，可以“打开版本 B 编辑”或“保留当前版，另一版移入回收站”（可恢复）。

两种方式都不展示工作流内部节点；生成提示会随需求一并发送，在助手会话里可以看到原文。

## 改动

- 后端：
  - `documents.ai_draft_start` 新增 `variants`（1/2）。两版共享 `variant_group`，B 版的请求标识是 `<request_id>_b`，重复提交不会重复生成。快速模式在发给模型的需求后附加“不要提问”。
  - 新增 `documents.ai_guided_start`（建会话并以 draft 模式发送带提问要求的需求，不预建文章）和 `documents.variants`（列出同组版本）。
  - 文章列表行带 `variant` / `variant_group`。
- 前端：`ArticleHome.tsx` 起草方式选择与两版选项；新增 `DocumentVariants.tsx`；侧栏加“两版对照”页签（只有两版文章才显示）；编辑器顶部加版本横幅。

## 本地验收（需要模型）

1. 快速生成一篇：列表出现“生成中”，完成后成为 AI 初稿；模型不应再停下来提问。
2. 勾选两个版本：列表出现版本 A、B；打开 A → “对照另一版”能看到 B 全文；“保留版本 A”后 B 进入回收站。
3. 引导式：切到助手，出现提问框；答完后生成候选稿，点“存为文章”。
