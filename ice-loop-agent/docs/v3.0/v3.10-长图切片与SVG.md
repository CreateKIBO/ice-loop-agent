## 长图与切片

“手机预览与交付”新增 **长图与切片**：选宽度（375 / 414 / 750）和每张大约多高（800–2400px），点“导出长图”，再选导出位置。

- **链路**：
  1. 引擎按当前交付版本生成长图页面：手机版心，带标题和作者；没有脚本，内容安全策略只允许 data: 图片。
  2. 桌面主进程在隐藏窗口里载入页面，按视口逐屏滚动截图。视口不超过屏幕工作区，最后一屏对齐底部。
  3. 引擎把各屏拼成一张长图，在每个目标切点上方 160px 内找最空白的一行切开，尽量不切断文字和图片。
- **输出**：新目录里有 `长图.png`、`切片/01.png…` 和 `manifest.json`（记录版本、像素尺寸、设备像素比、各切片位置和文件 hash）。
- **授权**：沿用导出图文包的 `ice:choose-export-dir` 授权链：目录只能由系统对话框选择，不能覆盖已有目录，先写临时目录再整体改名。
- **限制**：长于 60000 CSS 像素的文章需要分篇导出。导出长图不算交付记录，也不等于已发布。切片依据像素行亮度而非段落结构；连续底色、长图片或附近无空白时仍可能切开内容，需查看切片边缘。

## SVG 专项（评估与已实现部分）

| 方式 | 结论 |
|---|---|
| SVG 文件 → 图片 | **已实现**。插入行的“SVG”按钮：在隐藏窗口里只用 `<img>` 渲染 SVG（图片上下文不执行脚本、不加载外链），截成 PNG（默认 1080px 宽，过高时按比例缩窄）插入正文。原 SVG 另存在运行目录 `imports/<公众号>/<sha256>.svg`，图片来源显示“SVG 转图” |
| 交互/动画 SVG 原样交付 | **暂不做**。第三方编辑器的交互 SVG 依赖公众号后台对 `<svg>` 的特定处理，粘贴后是否保留、能否通过审核都需要真机验证。SVG 里还可能带脚本、事件和外链，需要专门的白名单清洗。按报告“兼容、性能及用户价值验证后扩展”的要求，先保留为只读原件，待实测后另立需求 |
| 粘贴内容里的 `<svg>` | 维持现状：作为未支持模块保留只读原件，交付时按设置降级 |
