# v3.25 编辑器里的多图文状态；发布授权边界草案（2026-11-08）

## 编辑器里的多图文状态

v3.24 的“尚未做”：在编辑器里看不到这篇属于哪组多图文。现在交付面板「公众号草稿箱」下逐组显示：

- “多图文第 N 篇（共 M 篇：《…》《…》）· 同步于 …”
- 这篇在那组草稿里是不是最新的稳定版本：“草稿里是这篇最新的稳定版本” / “这篇有新版本还没同步到这组”
- 同组文章被移入回收站时标出“（已移入回收站）”
- 「打开这组」：按原顺序打开多图文对话框，可直接检查、更新（对话框按需加载）

后端：`wechat.status` 带 `document_id` 时多返回 `groups`（最多 10 组，最近同步的在前）。

## 发布授权边界草案

[发布授权边界：方案草案](../上线准备/发布授权边界-方案草案-2026-11-08.md)。只界定边界和待决定事项，**没有实现发布、群发或定时**。要点：

- 区分“草稿已同步 / 发布已提交 / 已发布 / 群发已完成”，不互相推断。
- 建议第一期只做“提交发布 + 结果对账”；群发、定时另立项。
- 账号级开关默认关闭；每次发布确认绑定冻结版本 + 草稿 ID + 后台指纹，任何一项变化确认失效。
- 列出 6 个需要作者决定的事项和实现前必须核实的接口事实。
