# v3.23 留言设置与封面裁切（2026-11-08）

v3.22 的“尚未做”里有两项：留言开关固定为关闭；封面不裁切，比例以后台显示为准。这一轮把两项放进“文章设置”，同步到草稿箱时一起写入。

## 留言

文章设置 →「留言」：

| 选项 | 写入草稿 |
|---|---|
| 关闭留言（默认） | `need_open_comment = 0` |
| 所有人可留言 | `need_open_comment = 1`，`only_fans_can_comment = 0` |
| 仅关注者可留言 | `need_open_comment = 1`，`only_fans_can_comment = 1` |

设置随版本保存，也写进导出图文包的 manifest（`article.comments`）。复制粘贴的文章需要在后台自己设置。

## 封面裁切

公众号封面有两种显示方式：消息列表里的 **2.35:1 大图**，以及转发卡片、小图位置的 **1:1**。文章设置的封面下方多了两个预览，各带一个滑块：

- 图片比目标比例更宽时，滑块左右移动裁切框；更高时上下移动。裁切框始终取该比例下最大的范围。
- 只记录位置（0–1 的归一化坐标），不修改原图。同步时作为 `pic_crop_235_1`、`pic_crop_1_1`（`x1_y1_x2_y2`）写入草稿。
- 没动滑块时显示“默认居中”，不写入裁切坐标，由后台按默认处理。点「恢复默认居中」可清除。
- 裁切记录了它针对的是哪张封面（`coverCrop.for`）。换封面或正文第一张图变了，旧的裁切自动失效，不会套到别的图上。

## 数据

`content.info` 新增两个字段，随版本冻结：

```json
{ "comments": "fans",
  "coverCrop": { "for": "resource-…", "235": [0, 0.1, 1, 0.5255], "11": [0.2, 0, 0.8, 1] } }
```

校验规则：`comments` 只能是 off/all/fans，off 不写入；`coverCrop` 必须带 `for`，坐标在 0–1 之间，且 x1 < x2、y1 < y2。
