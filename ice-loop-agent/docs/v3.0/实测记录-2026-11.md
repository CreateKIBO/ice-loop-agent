## 9. 自动汇总

```powershell
python tools/field-report.py --runtime <数据目录> --perf 结果.json --out 实测汇总.md
```

- 先用 SQLite 备份接口把 `app.db` 复制到临时目录再读，原数据不被修改或迁移；应用开着也可以运行。
- 报告包含：环境与数据库版本；每个公众号的文章、版本、交付、发布登记、提案数量；技能组合；全部兼容测试稿的三段记录与统计；最近一次作者试用报告；性能结果（可传多个 `--perf` 对比）。
- 不含正文、密钥、提示词或模型输出。
