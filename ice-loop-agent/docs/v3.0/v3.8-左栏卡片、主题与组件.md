# v3.8 左栏“正在编辑”卡片、排版主题与组件（v3.2 遗留 + P2，2026-11-06）

## 左栏“正在编辑”（v3.2 布局稿遗留）

打开文章时，左栏顶部显示“正在编辑”卡片：
- **封面缩略图**：取文章设置里指定的封面，否则取正文第一张图。
- **标题与状态**：实时保存状态、字数，以及“尚未存为版本”提示。
- **快捷入口**：“AI 助手”“预览与交付”。
- **最近 4 个历史版本**：点击直接打开编辑器的版本侧栏，避免在左栏里误恢复。

列表数据新增 `cover_resource_id`。编辑器通过 `documentEditingStore` / `documentPanelStore` 和左栏同步。

## 排版主题（P2“更多主题”）

“一键排版”新增主题选择（带小样）：

| 主题 | 特点 |
|---|---|
| 简洁 | 原有主题，左边线小标题。**交付 HTML 与 v3.0 逐字一致**（已用旧渲染器对照验证），旧文章不受影响 |
| 杂志 | 居中标题、细线分隔、斜体居中引用，适合长文与随笔 |
| 科技 | 色块小标题、深色代码块、灰底引用，适合技术文 |
| 温暖 | 圆角色块小标题、暖色引用、圆角图片，适合生活类 |

- 主题都基于品牌色。
- 编辑器里显示近似效果；手机预览与复制/导出用引擎渲染，以交付结果为准。

## 组件（P2“卡片/多图等组件”）

插入行新增：

- **提示卡片**：带底色的卡片，有品牌色、说明、提示、注意四种颜色，标题可选，卡片里可以写段落和列表。光标在有文字的段落里时，会把这一段包进卡片。交付为带左边线的圆角色块；纯文本里标题写成“【标题】”。
- **多图**：2–9 张图片，按 2 列或 3 列并排。每张图可以写说明，整组可以写图注，支持左右调整顺序。
  - 交付用 `inline-block` 百分比宽度并排，不依赖 flex。
  - 图片序号、缺图检查、导出包、封面推断都把多图里的图算进去。

Markdown 投影：卡片转为引用块（标题加粗），多图转为逐张图片。

## 验证

- `python -m unittest tests.test_v3_components`：4 个用例通过，覆盖卡片的规范化/渲染/纯文本/Markdown、多图的序号/缺图/导出/封面、四个主题输出互不相同、非法主题拒绝。
- `tests.test_v3_documents` 等 v3 套件通过。另外用旧版 `render.py` 对照了“简洁”主题的单图、缺图、占位模式输出，结果逐字一致。

## 本地验收

1. 打开文章：左栏出现“正在编辑”卡片，改正文时状态会变化；点版本跳到编辑器的版本侧栏。
2. “一键排版”切换四个主题：编辑器和“手机预览与交付”都应变化；切回“简洁”，复制结果与以前相同。
3. 插入“提示卡片”和“多图”（3 列、调整顺序、写说明），复制到公众号后台，检查卡片底色和图片并排效果。

> 多图并排和卡片底色在公众号后台的实际保留情况需要真机确认。报告要求 P2 先做兼容验证再扩展，如有问题请告诉我实测结果。
