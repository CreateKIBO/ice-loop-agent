# v3.15 写作技能：导入导出、版本历史、复制与恢复预装（2026-11-08）

开发报告 §6 SK-00：“多技能组合、导入导出与版本管理界面仍是后续功能。”《可插拔技能系统》方案 §1、§4、§7 要求技能可以查看、修改、复制、导入、导出，编辑产生新版本，卸载不删历史，恢复默认由用户主动触发。这一轮把其中**导入导出、版本管理、复制、恢复预装**做完；多技能组合与栏目/文章作用域仍留到后续。

## 用法（设置 → 写作技能）

| 位置 | 操作 | 说明 |
|---|---|---|
| 左侧技能列表下方 | **导入技能** | 选 `.md` / `.txt` 或 ZIP 包 → 预览（可改名称）→ **加入技能列表** → **保存设置** 才生效 |
| 同上 | **恢复预装技能** | 列出预装的“通用写作”“ICE 写作方法”：缺少的可**重新加入**；已有的可**用预装内容替换编辑区** |
| 编辑区顶部 | 版本号与来源 | 例如“v3 · 导入自 随笔.md（2026-11-08 10:00）”“复制自 ICE 写作方法 v2”“恢复自 v1” |
| 同上 | **复制为新技能** | 名称加“副本”，规则一起复制 |
| 同上 | **导出** | 桌面应用弹出保存对话框，导出**上次保存的版本**（编辑区未保存的修改不包含，会提示） |
| 同上 | **版本历史** | 列出每一版的时间、字数、规则数、来源；点某一版可预览、**导出这一版**、**载入到编辑区** |

导入、复制、恢复预装、载入历史版本都只改编辑列表；点“保存设置”才生效，并记成新的一版。任何一种都不会自动把技能设为主技能。

## 文件格式

导出的 Markdown 可原样再导入：

~~~markdown
---
name: "我的方法"
version: 3
format: ice-writing-skill/1
exported_at: 2026-11-08T10:00:00+08:00
source_id: custom-…
---

写作指令正文……

<!-- 以下为检查规则（JSON），导入时读取；不需要时可整段删除 -->
```json ice-skill-rules
{ "title_max_chars": 30 }
```
~~~

导入时也接受：

- 普通 Markdown / 文本：第一行 `# 标题` 作为名称，没有就用文件名；整篇作为写作指令。
- 外部 `SKILL.md`（前置字段 `name`、`description`）：正文为空时用 description。`allowed-tools`、`permissions`、`model`、`hooks` 等声明**不生效**，预览里会说明。
- ZIP 包：根目录（或唯一的顶层文件夹）里的 `SKILL.md`，可选 `skill.json`（`name`、`version`、`rules`、`instructions` 指向的入口文件）。`references/`、`examples/` 等文件首期不导入，脚本和程序文件不导入也不运行，都在预览里列出。
- UTF-8（含 BOM）；不是 UTF-8 时按 GBK 读并提示核对。

## 限制与安全

- 单个文件 ≤ 1MB，Markdown ≤ 20 万字；写作指令仍是单个技能 ≤ 12000 字（超出直接报错，不截断）。
- ZIP：≤ 100 个文件、解压后 ≤ 4MB；拒绝绝对路径、`..`、盘符路径、链接文件和非常规压缩方式。
- 检查规则逐项校验：不认识的字段、超出范围的值单独丢弃并提示，其余照常导入。
- 指令里出现“忽略之前的规则”“API key”“上传”等字样时提示：技能只影响写作与检查，不会因此获得任何工具、文件或发布权限。
- 解析（`skills.import_parse`）不写数据库；来源（文件名、sha256、导入时间、格式、原版本号）随技能和每个版本保存，只作记录，不代表可信。

## 数据

- 迁移 v26：`writing_skill_versions(account_id, skill_id, version, name, instructions, rules_json, content_hash, source_json, created_at)`，按公众号隔离。
- 保存时：先把改动前的版本补进历史（旧数据、预装技能第一次被改），再写入有改动的新版本；没改动不记新版。
- 移除技能不删历史；同一标识重新加入时版本号接着历史往下编（例如移除 ICE 写作方法 v3 后恢复预装 → v4）。
- 生成任务与重试仍使用开始时冻结的技能快照，不受之后的导入或恢复影响。

## RPC

| 方法 | 说明 |
|---|---|
| `skills.versions` `{skill_id}` | 版本列表（新到旧），含当前在用版本 |
| `skills.version` `{skill_id, version}` | 某一版的完整内容 |
| `skills.defaults` | 预装技能原始内容 |
| `skills.export` `{skill_id, version?}` | `{file_name, markdown, sha256}` |
| `skills.import_parse` `{file_name, text \| data_base64}` | `{skill, warnings, ignored_files}`，不写入 |

主进程新增 `ice:export-skill`（保存对话框写文件）；`skills.import_parse` 的请求上限放宽到 2,000,000 字符。
