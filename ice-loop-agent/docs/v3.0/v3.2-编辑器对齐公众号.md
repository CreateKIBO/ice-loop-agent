## 改动

**界面**（`DocumentEditor.tsx`、`documents.css`）

| 公众号编辑页 | 本应用 |
|---|---|
| 插入行（图片/超链接/…） | 插入行：图片、超链接、引用、分隔线、代码块、待配图位。视频、小程序、投票等公众号专属组件无法通过粘贴交付，没有加入 |
| 格式行 | 撤销/重做、清除格式、段落类型、选中文字字号（空值显示全文字号）、加粗/斜体/下划线/删除线、文字颜色、**背景色（高亮）**、对齐、**首行缩进**、全文行距/段距/**字间距**、列表、行内代码、链接 |
| “请在这里输入标题”与 0/64 | 标题输入框加 **N/64 计数**，超过 64 字标红，交付时给出提示（不阻止保存） |
| “请输入作者” | **作者**字段在标题下方，公众号上限 8 字，超出时计数标红并在交付时提示 |
| 一键排版 / 文章设置（右下浮动） | 右下浮动按钮：“一键排版”打开全文排版设置；“**文章设置**”可设封面（默认取正文第一张图，也可另选）、摘要（120 字）、原文链接 |
| 底栏“正文字数 / 保存为草稿 / 预览 / 发表” | 底栏：正文字数、保存状态、历史版本、保存版本、手机预览与交付。没有“发表”按钮，发布仍需在后台手动完成并回来登记 |
| 默认 17px | 新文章默认正文字号改为 **17px**；已有文章保持原设置 |

**规范值与交付**（`schema.py`、`render.py`、`service.py`、`html_import.py`）

- 新增：
  - `textStyle.backgroundColor`（#RRGGBB）
  - 段落属性 `indent`（首行缩进 2em）
  - `style.letterSpacing`（0/0.5/1/1.5/2px）
  - `content.info{author, summary, sourceUrl, coverResourceId}`（随版本冻结）
- 兼容性：`letterSpacing` 和 `info` 只在设置过时才写入，没设置过的旧文章内容 hash 不变。
- 交付渲染：
  - 输出背景色、首行缩进和字间距。
  - 返回 `info`/`cover`。
  - 标题超过 64 字、作者超过 8 字时给出警告。
  - 没有封面时给出提示。
- 导出包：
  - 另存 `封面.*` 文件。
  - `manifest.article` 记录作者、摘要、原文链接和封面来源。
- 粘贴导入：行内背景色映射为高亮；`text-indent` 映射为首行缩进。
- 编辑器内部复制粘贴：颜色从浏览器读出的 `rgb()` 统一转为 #RRGGBB，修复了内部复制后颜色丢失的问题。

## 本地验收

1. `cd desktop\ui && npm run typecheck && npm run build`
2. 新建文章：
   - 标题计数，超过 64 字时应标红。
   - 作者计数。
   - 高亮、首行缩进、字间距。
   - 右下“文章设置”中另选封面、填摘要。
3. 在“手机预览与交付”中看预览是否带作者、封面和摘要信息；复制到公众号后台，核对高亮、缩进和字间距是否保留。
4. 导出图文包：检查是否有 `封面.*` 文件，以及 `manifest.json` 的 `article` 字段。
