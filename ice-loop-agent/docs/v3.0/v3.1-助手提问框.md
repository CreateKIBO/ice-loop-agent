# v3.1 助手提问框（2026-11-05）

> GitHub 推送前复核：当前源码版本仍为 `3.0.0-alpha.1`，本标题表示功能迭代，不代表已打包发布。Codex 使用现有真实依赖执行了前端类型检查、构建；`test_v3_documents`、`test_writing_skills`、`test_chat_send_receipts` 合计60项通过，桌面 `ui-a11y` / `chat-delivery` 合计13项通过。此次未运行真实模型、Electron 或提问框完整浏览器交互验收；下方云端验证与静态样张不能替代这些项目。

需求来源：P0 验收后用户反馈，希望助手提问时有一个类似常见 Agent 的提问框，可以逐题作答、从选项里选择。

## 改动

**提问框**（`QuestionDock.tsx`）：在“助手”中，如果最新一条回复带有待答问题，输入框上方会出现提问框。
- **导航**：顶部有题目标签，答完的题打勾，可以点标签跳到任意一题；最后一个标签是“提交”。
- **作答方式**：
  - 每题只显示一个问题。选项以卡片形式列出，可以带一句说明，推荐项排在第一位。
  - 支持单选和多选。单选题选中后自动跳到下一道未答的题。
  - 每题都可以“其他：自己填写”（多选题里是“补充其他”）。
  - 每题都可以选“不确定，交给助手判断”。
- **提交**：最后一步列出全部回答，点击任意一条可以回去修改。知识引用的设置收在折叠项里。点“提交回答并继续”后，助手据此继续生成。
- **快捷键**：数字键 1–4 选择选项，Enter 进入下一题，← 回到上一题，Esc 收起，在文本框里按 Ctrl+Enter 也能前进。
- **收起与自由回复**：收起后提问框变成一条提示，可以直接在输入框里自由回复。这个路径沿用原来的“自由回答”逻辑，问题保持待答。
- **草稿保存**：作答草稿自动存到本机，切换会话或重启后仍在；旧版本留下的纯文本草稿也能读出来。

**对话流**（`ClarificationForm.tsx`）：只显示问题列表和提示；已经回答过的问题显示回答摘要。

**引擎**（`creative_chat.py`）：
- 每次最多 4 个问题（原来是 3 个）。
- 问题新增可选字段：`header`（短标签）、`multiple`（多选）。
- 选项支持写成 `{"label","description"}`，入库时规范为 `options` 加平行的 `details`。
- 没有新字段的旧消息，存储格式完全不变。
- 提示词要求：每题只问一件事，推荐项放第一位，不要自己提供“其他”选项。

## 本地验收

1. `cd desktop\ui && npm run typecheck && npm run build`
2. 在“助手”中让 AI 起草一篇信息不足的文章（例如只给一个主题）。应出现提问框，逐项检查：选项和说明、单选后自动跳题、多选、自己填写、交给助手判断、上一题/下一题、提交页修改、数字键和 Esc。
3. 收起提问框，在输入框里直接回复，助手应把它当作自由回答处理。
4. 答到一半切换会话再回来，或者重启应用，草稿应该还在。
