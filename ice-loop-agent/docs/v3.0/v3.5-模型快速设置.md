# v3.5 模型初次配置的简单路径（P1，2026-11-06）

对应开发报告 P1 最后一条：“模型初次配置先提供一个供应商、一个模型/Key的简单路径，角色路由保留高级入口。托管模型服务不作为本地优先版本的默认前提。”

## 改动

- “模型与 Key”对话框顶部新增 **快速设置：一个模型负责全部文字**（`desktop/ui/src/app/QuickModelSetup.tsx`）：
  1. 选供应商（通义千问、DeepSeek、Kimi、GLM、豆包、MiniMax，沿用已有预设）；模型 ID 默认取预设，可改；
  2. 粘贴 API Key（已有 Key 可留空沿用）；
  3. 点 **保存并测试**，依次执行：加密保存 Key → 保存模型 → 把该模型设为全部文字环节的主模型 → 测试连接。每一步完成会打勾；中途失败时，已打勾的步骤已经保存，修正后再点一次即可。
- 原来的预算、文字分工、六个供应商卡片和生成上限全部保留，收进 **高级设置** 折叠区。已配置多个供应商 Key 时默认展开，否则默认收起。
- 没有新增后端接口：复用 `saveKey`（主进程加密）、`models.save`、`models.routes_save`（带 routes_hash 并发校验）、`models.probe`。
- 快速设置的未保存输入接入原有的“离开前提醒”；Enter 提交时避开中文输入法组词。

## 本地验收

1. 新装或清空 Key 后打开“模型与 Key”：顶部是快速设置，高级设置收起。
2. 选一个供应商、粘贴 Key、点“保存并测试”：四步依次打勾，提示“模型已可用”；展开高级设置，文字分工中各环节主模型都应是这个模型。
3. 故意填错 Key：前三步打勾，测试连接失败并显示原因；改对 Key 再点一次应通过。
4. 有未保存的 Key 时关闭对话框，应提示有未保存修改。
