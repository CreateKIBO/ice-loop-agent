## 已知限制与后续

- `desktop/package-lock.json` 两处根版本已由后续联调对齐为 3.0.0-alpha.1，未改变依赖图。
- 经典界面（`renderer/`）的执行入口没有逐个删除。主进程白名单和引擎已经拒绝这些调用，经典界面点击后会看到退场提示。
- 新工作台的原任务入口现使用 `LegacyArticleView`，保留历史输出和旧编辑器工作草稿查看/另存。旧 `ArticleEditor` 实现仍留在源码供历史兼容，不作为 v3 原任务入口。
- 粘贴转换只对常见公众号/网页结构做了样本验证；真实 Word 和公众号后台 HTML 需要通过 B-05 及后续样本补充。
- 交付复制在剪贴板中嵌入图片：原图不超过 2MB 且宽度不超过 1920 时用原图字节，否则用缩小副本，并在问题清单中注明。微信是否接受内嵌图片以 B-05 实测为准；不接受时请使用“导出图文包”，按编号上传。
