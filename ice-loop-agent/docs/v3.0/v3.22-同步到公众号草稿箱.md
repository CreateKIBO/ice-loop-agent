# v3.22 同步到公众号草稿箱（2026-11-08）

之前交付只有三条路：复制到剪贴板再粘贴、导出图文包、导出长图。粘贴时图片要靠后台自己转存，失败了也看不出来；封面、作者、摘要每次都要手动重填。路线图《一体化公众号 Agent》§6 把“上传资源 → 同步草稿 → 回读对账”列为交付流水线的前几步。这一轮做到**写进草稿箱**为止。

**不做发布、群发和定时发布**：开发报告要求“自动发布另立需求与授权边界”。草稿写入后，作者在公众号后台预览、发布，再回应用登记发布。

## 用法（手机预览与交付）

1. **设置公众号接口**（每个公众号一次）：
   - AppID：公众号后台“设置与开发 → 基本配置 → 开发者 ID”。
   - AppSecret：同一页的开发者密码。
   - IP 白名单：把本机出口 IP 加进去。不知道 IP 时先点测试，失败提示里会显示需要添加的 IP。
   - 点「保存并测试连接」，提示“连接正常”即可。
2. 预览没有阻断问题时，点 **同步到草稿箱**：
   - 第一次：新建草稿。
   - 之后：更新同一篇草稿，界面显示“已同步 · 时间 · 草稿尾号 · 与当前版本是否一致”。
3. 同步后 **登记一次发布** 可用（草稿同步算作一次交付）。

## 同步了什么

| 字段 | 来源 | 处理 |
|---|---|---|
| 标题 | 文章标题 | 超过 64 字不同步，先缩短 |
| 作者 | 文章设置 · 作者 | 超过 8 字截断并提示 |
| 摘要 | 文章设置 · 摘要 | 超过 120 字截断并提示 |
| 原文链接 | 文章设置 · 原文链接 | 原样 |
| 封面 | 文章设置里指定的封面，否则正文第一张图 | 上传为永久素材；没有封面时不同步，并提示怎么补 |
| 正文 | 与“复制到公众号”同一个渲染器、同一个冻结版本 | 图片换成微信返回的地址；正文须少于 2 万字、HTML 小于 1MB |
| 正文图片 | 原图 | 接口只收 jpg/png 且小于 1MB：webp 转 JPEG，过大的逐级压缩，必要时缩到 1920px 宽；动图变成静态图；每处转换都会提示 |

同一张图（按内容哈希）在同一公众号、同一 AppID 下只上传一次，以后直接复用；不跨公众号复用远端地址或素材 ID。

## 不覆盖后台改动、不重复建草稿

- **后台改过**：更新前先回读后台草稿，和上次同步后记下的正文指纹比对。指纹只看去掉标签和空白后的文字，因为后台会改写 HTML。不一致时停下，让作者选「另建一篇草稿」或「用当前版本覆盖」。
- **后台删了**：自动新建一篇并提示。
- **结果未知**：每次写草稿前先记操作日志。写入时网络中断，日志标为“结果未知”；下次同步先请作者到后台核对，确认后再「我已核对，继续同步」，不会自动再建一篇。
- **同时点两次**：同一篇文章同一时间只允许一个同步。
- **切换中途**：同步进行中离开文章或切公众号，结果只在提示里说明，不写当前页面（同 v3.21）。

## 凭据与安全

- AppSecret 由桌面主进程用系统凭据加密，保存在 `credentials.json`（键名 `wechat-<公众号标识>`）；启动时只送进引擎内存，不写入数据库或日志。界面只知道“已保存 / 未保存”。
- 调用凭据用 `stable_token` 接口获取，不会让其他工具已取得的凭据失效；凭据失效（40001/42001）时自动重取一次。
- 常见错误码都有中文说明：IP 白名单、AppSecret 失效、未开通接口权限、调用次数用完、标题/摘要/作者过长、正文过长等。
- 只调用 `stable_token`、`media/uploadimg`、`material/add_material`、`draft/add`、`draft/update`、`draft/get`。

## 数据（迁移 v29）

| 表 | 用途 |
|---|---|
| `wechat_config` | 每个公众号的 AppID 与上次测试结果 |
| `wechat_assets` | 本地图片哈希 → 远端图片地址 / 封面素材 ID（按公众号 + AppID） |
| `wechat_drafts` | 每篇文章最近一次同步：草稿 ID、版本、交付指纹、后台正文指纹 |
| `wechat_operations` | 外部写入日志：started / succeeded / failed / unknown |
| `document_deliveries` | 重建以增加交付类型 `wechat_draft`；原记录逐行保留 |

## 接口

| 方法 | 说明 |
|---|---|
| `wechat.status` `{document_id?}` | 是否已设置、AppSecret 是否已保存、上次测试；带文章时附最近同步与“结果未知”的操作 |
| `wechat.configure` `{appid}` | 保存 AppID（AppSecret 走主进程 `saveKey('wechat-<公众号>')`） |
| `wechat.test` | 取一次调用凭据，记录结果（后台执行） |
| `wechat.draft_sync` `{document_id, version_id?, base_revision?, mode: auto\|new\|overwrite, checked_unknown?}` | 同步（后台执行）；冲突或需核对时返回 `conflict` / `needs_check`，不写入 |
| `wechat.resolve_unknown` `{document_id}` | 把“结果未知”的操作标为已核对 |

## 尚未做
