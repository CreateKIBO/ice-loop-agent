# v3.19 技能参考资料与示例（2026-11-08）

v3.15 导入技能包时，`references/`、`examples/` 一律不导入，只提示“请把要点写进指令正文”。《可插拔技能系统》方案 §4 要求“首期支持单个 Markdown 文件，以及上述目录/ZIP”，§5 要求“按阶段只加载需要的部分”。这一轮让技能带上文字类的参考资料和示例，并且每个阶段只放进它需要的那些。

## 用法（设置 → 写作技能 → 编辑某个技能）

「参考资料与示例」区：

| 操作 | 说明 |
|---|---|
| 添加文件 | 选 `.md` / `.txt`，可多选。文件名含“范文 / 示例 / 样例 / example”的自动标为**示例**，其他为**参考资料** |
| 类型 | 参考资料（风格指南、术语表、栏目规范…）/ 示例（范文、片段） |
| 阶段 | 构思（讨论、选题、大纲、拟题、图位）/ 写作（初稿、改稿、助手改写扩写）/ 审阅；至少选一个 |
| 查看 / 移除 | 查看全文；移除只去掉引用 |

默认阶段：参考资料用于三个阶段，示例只用于写作。改动和指令一样，点「保存设置」才生效，并记一个新版本。只改阶段或类型也算修改。

## 进入提示词的方式

| 场景 | 阶段 |
|---|---|
| 助手会话：讨论 / 配图 | 构思 |
| 助手会话：生成初稿 / 改稿；文章 AI 起草 | 写作 |
| 文章内助手：改写、扩写、压缩、改语气、按要求修改 | 写作 |
| 文章内助手：图位建议 | 构思 |
| 旧流程节点：选题、调研、大纲、拟题、配图计划 / 初稿 / 审校 | 构思 / 写作 / 审阅 |

- 资料以只读数据附在技能说明之后，并注明：其中的指令不改变权限与流程；示例只学习结构、语气和手法，不照抄内容和事实。
- 数量上限：快照最多保存 24,000 字，单次请求最多放 12,000 字（文章内助手 6,000 字），按“主技能在前、辅助技能在后”的顺序取，超出部分截断并标注。
- 资料正文存进生成时的技能快照，所以重试、追问后继续和回答问题后继续写作，都用同一份资料。
- 技能里没有参考文件时，提示词和快照与之前完全一样。

## 存储

- 迁移 v28：
  - `writing_skill_files(account_id, file_id, name, kind, text, sha256, chars, created_at)`：正文**不可变**。同名、同类型、同内容的文件复用同一条。
  - `writing_skill_versions` 增加 `files_json`，记录每一版引用了哪些文件和阶段，所以载入旧版本时文件也一起恢复。
- 技能设置里只存引用 `files: [{id, name, kind, stages, chars}]`。保存时检查引用的文件确实存在且属于当前公众号。
- 上限：单个文件 ≤ 2 万字；每个技能 ≤ 10 个；每个公众号 ≤ 500 个。
- 复制技能会共用同一批文件；移除技能或移除引用不删文件正文（历史版本仍可能用到）。

## 导入导出

- **导出**：有参考文件的技能导出为 ZIP，内含 `SKILL.md`、`skill.json`（含 `files: [{path, kind, stages}]`）、`references/`、`examples/`；没有参考文件时仍导出 Markdown。
- **导入 ZIP**：
  - 文字文件（`.md/.markdown/.txt`）一起导入。类型与阶段优先取 `skill.json` 的声明；没有声明时，`examples/`、`example/`、`samples/` 下的文件算示例，其余算参考资料。
  - 图片、二进制文件、脚本，以及超过单个 2 万字或合计 6 万字、超过 10 个的文件，都列在“未导入”里，并说明原因。
  - 预览里列出“一起导入的参考文件”；点“加入技能列表”时才保存正文。
- 主进程导出 ZIP 时写二进制文件；开发浏览器环境不能保存 ZIP，会提示去桌面应用导出。

## 接口

| 方法 | 说明 |
|---|---|
| `skills.files_add` `{files: [{name, kind, text}]}` | 保存正文，返回引用（含默认阶段）；1–10 个 |
| `skills.file_get` `{file_id}` | 读取全文（查看用） |
| `skills.import_parse` | ZIP 结果新增 `files: [{name, path, kind, stages, text, chars}]` |
| `skills.export` | 有参考文件时返回 `{file_name: *.zip, data_base64}` |
| `skills.version` | 新增 `files` |
