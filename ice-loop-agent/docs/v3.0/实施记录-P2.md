## 新增接口

- 渲染层：`documents.batch / plan / calendar / suggestions / suggestions_dismiss / library / image_tags`
- 主进程专用：`documents.long_image_page / long_image_compose / svg_import`；IPC `ice:document-long-image`、`ice:document-svg-image`
- 规范值：主题 `magazine/tech/warm`；块 `callout`、`imageGroup`；文章运营元数据 `meta_json.planned_date`（不在 `content.info`）；图片资源上的 `tags`

## 兼容性

- “简洁”主题的交付 HTML、纯文本、图片清单和问题列表，已用旧版 `render.py` 对照，逐字一致。旧文章的内容 hash 和交付结果不变。
- 新组件只在用户插入后才出现在规范值里。不认识它们的旧版本应用打开时，会降级为只读块。
