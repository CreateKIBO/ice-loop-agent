# v3.9 运营增强：批量整理、发布日历、建议管理、素材标签（P2，2026-11-06）

对应开发报告 P2 中的“素材标签、建议管理、发布日历和批量整理”。所有操作按当前公众号隔离，不改正文、不自动发布。

## 文章首页四个视图

`全部文章 | 发布日历 | 待处理建议 | 回收站`

**批量整理**（全部文章、回收站）
- 每行有勾选框，顶部可全选。
- 批量操作：移入回收站、恢复、设系列、清除系列、设计划日期、取消排期。
- 一次最多 200 篇，在同一事务里执行：任何一篇不属于当前公众号、或还在生成中，整批都不改。
- 本来就是目标状态的文章会跳过，并在提示里说明。

**发布日历**
- 按月显示“计划发布”（蓝）和“已登记发布”（绿）。已发布的文章不再重复显示计划；点条目打开文章。
- 下方列出“未排期”的文章，两种排期方式：直接选日期；或点“排期”后再点日历上的某一天。
- “本月计划”里可以取消排期。
- 计划日期只用于排期，存在文章信息里，不触发任何发布。列表行显示“计划 MM-DD”。

**待处理建议**
- 集中列出各篇文章里待采纳、生成中、失败的 AI 修改提案，带操作类型、修改处数和已过期处数。
- “去处理”打开文章并直接打开 AI 助手侧栏。
- 可以批量放弃：正文不改，提案记录仍保留在各文章的助手里。

## 素材库与标签

编辑器插入行新增 **素材库**：
- 浏览当前公众号导入过的所有图片（粘贴、截图、本地文件、Word、裁切结果），按名称、标签、原文件名搜索，按标签筛选（显示各标签的数量）。
- 选中一张后可以编辑标签（逗号或空格分隔；每张最多 10 个，每个最多 20 字）；插入正文时双击图片或点“插入正文”。
- 每页 40 张。

- RPC：`documents.batch`、`documents.plan`、`documents.calendar`、`documents.suggestions`、`documents.suggestions_dismiss`、`documents.library`、`documents.image_tags`（支持 replace/add/remove 与多图），均已加入渲染层白名单。
- 文章列表行新增 `planned_date`。
- 后端集中在 `ice_agent/documents/ops.py`。

## 本地验收

1. 勾选 3 篇 → 设系列“编译器笔记” → 列表显示系列；再“移入回收站”→ 回收站视图里勾选恢复。
2. 发布日历：给一篇排期，再给另一篇登记发布，确认颜色与位置；点条目能打开文章。
3. 在两篇文章里各发起一次 AI 改写不采纳 → “待处理建议”列出两条；“去处理”跳到助手；勾选后放弃。
4. 编辑器“素材库”：给几张图打标签，按标签筛选，插入正文。
