# v1.5.2 预算管理与交互体验

预算现在有两个直接入口：窗口顶部的「AI 预算」，以及侧栏「模型与预算」页面最上面的预算卡片。无需向下找供应商设置。这里的预算指每篇任务的模型请求次数上限，费用仍由模型供应商按实际使用计费。

## 遇到调用上限时怎样继续

在配图提示词窗口，点击「调整本篇预算」，即可查看本篇的已用、剩余和上限。提高「本篇调用上限」并保存，关闭预算窗口，再点击「根据文章与风格 AI 重拟」。制作任务详情也提供同样入口。

「全局默认预算」只影响新任务。调整它不会批量修改已有文章；已有任务需要保存各自的本篇预算。默认新写作任务24次，导入文章补图12次，可设置1–100次整数。失败的实际调用和重试也占次数；能力预检不兼容的请求不计入。

以前的导入稿补图任务将正文模型预算设为0，原意是保护原稿，新增加的提示词重拟却使用同一个预算。新版使用独立的补图预算：旧任务首次主动重拟时兼容到当前默认补图上限，正文预算仍为0。补图预算只能用于配图提示词节点，不能启用正文写作。同时修复重拟没有恢复任务保存的模型配置的问题，已有任务继续使用创建时选定的模型。

创作讨论是独立的会话请求，当前不纳入文章制作任务的次数预算。这里不是所有账号的人民币总费用上限。

## 界面与反馈

- 保留暖白、墨黑和信号蓝的品牌样式；统一按钮高度、圆角、图标大小及按钮行间距，模型Key输入框和保存按钮对齐。
- 修复普通输入框的全宽样式错误覆盖复选框，复选框和单选框使用明确尺寸。
- 弹窗限制在当前窗口内并支持滚动，长提示词的保存和重拟操作栏可以固定在可见区域。
- 操作按钮在请求期间显示转圈和忙碌状态，右下角提示正在处理的具体操作；请求结束恢复按钮。按钮宽度保持稳定。
- 消息提示支持关闭，预算不足提示提供调整入口；配图窗口原地提示恢复方法，并保留你的编辑。
- 使用本地打包的开源 [Motion](https://motion.dev/docs/press) 实现按压、[悬停](https://motion.dev/docs/hover)、弹窗、列表和消息进入过渡。不开启远程脚本。动效可设置为开启、关闭或跟随系统；主动开启可以覆盖系统减少动效设置，关闭时停止正在运行的动画。

请求状态基于实际进行中的操作，调用进度基于数据库真实记录。界面不提供虚构的生成百分比。

## 升级与数据

先保存正在编辑的内容，再运行 `release/ICE-Loop-Studio-1.5.2-Setup.exe`。安装器沿用现有关闭旧程序及恢复工作区流程；本次验收不对用户实际安装执行升级向导。免安装包为 `release/ICE-Loop-Studio-1.5.2-x64.zip`，完整解压到非C盘目录后运行。

原稿、已选图片、手工提示词和账号模型配置不会因修改调用上限而被替换。生图仍在内嵌TapNow网页手动完成，公众号发布仍由你审阅并操作。

回归结果、桌面截图和安装包核对见 `v1.5.2-验收结果.json` 与 `screenshots/v1.5.2/`。测试使用G盘隔离数据、离线模型和本地网页；不以离线测试推断真实模型输出质量。
