## 2. 设计取舍（供审阅）

- **对照正文来源**：面板打开时从 `candidates`（当前页真实数据）按 ID 取完整 body，不在选择状态中保存正文副本——翻页后 ID 失效即清空（简单可靠，满足 A6"有限 ID 状态"选项）。
- **目录**：复用 `markdownBridge.markdownHeadings`（AST 级，代码围栏伪标题天然不入），点击滚动用 offsetTop 定位（阅读视图 DOM），原文视图目录仍可定位（回读阅读 DOM 不可用时落回顶部——已知边界，未声称原文视图目录精确定位）。
- **回到开头**：reduced-motion 经 matchMedia 实时订阅（本组件内新建；Motion 的 useReducedMotion 在本组件引入成本不对称，且任务书禁止"只读初始值"包装——本实现是实时订阅）。

## 3. 建议复验点（Codex）

1. 对照面板在真实 chat 轮询下选择/正文是否稳定（本轮 trace 断言零写，但轮询期间 candidates 引用替换对 effectivePicks 的影响只有 loadedIds 过滤证据）。
2. reading-upgrade 的分页循环（最多 8 页）在更多历史候选下的行为。
3. 帮助新增条目与搜索索引的覆盖（本轮人工核对，未加帮助搜索专项）。

## 4. 已知边界

- 原文视图（pre）下局部目录点击落回面板顶部（阅读 DOM 不可用）；未声称精确。
- 复制文件名清单不含图片本体（文案已注明）；未读参考不计入。
- 对照面板 Esc 关闭依赖 Radix 顶层弹窗层级；与其他弹窗叠层未逐一验证（沿用 Dialog 既有契约）。
