# 持续迭代第 24 轮（2026-11-05，前端岛屿布局与岛内表面统一）

## 改动文件

`desktop/ui/src/` 下：

- `styles/island.css`（新增）：岛屿布局全部样式。面板宽度、显隐、分隔条、单面板逻辑不变；岛与边缘的距离做在 pane 的 padding 里，因此 `#ice-writing-pane` 在专注/窄窗口下仍为整窗宽（`layout-native.cjs` 的宽度断言依赖这一点）。显示切换不改 `display`，避免覆盖 `.ice-shell__body > [hidden]`。
- `styles/tokens.css`：新增 `--ice-canvas`、`--ice-island-*`、`--ice-focus-max`、`--ice-border-subtle/faint/focus`、`--ice-reading-max`。
- `components/ui.tsx`：在 feedback.css 之后加载 island.css。
- `app/WorkbenchShell.tsx`：顶栏改为画布上的 品牌 + Ctrl K 搜索按钮（打开既有命令面板 `paletteStore`）+ 胶囊分段布局按钮；三个 pane 内各包一层 `.ice-island` / `.ice-island-stack`。**按钮文案"会话与草稿 / 专注写作 / 恢复侧栏 / 任务与资料 / 写作区"、`.ice-shell-toolbar`、各 pane id 与 aria 属性保持原样**（layout-native 按精确文案点击）。`role="group" aria-label="工作区布局"` 从整条顶栏移到三按钮分组上。
- `features/chat/ChatPane.tsx`：AgentActionCards + Composer 外包 `.ice-action-dock`（DOM 顺序不变）。
- `features/tasks/RightPane.tsx`：拆为 `section.ice-island--resources`（知识检索 + 下载暂存）与 `section.ice-island--tasks`（制作任务 + WorkflowReview），数据、轮询、偏好逻辑不变。
- `features/chat/MessageBubble.tsx`：只改助手气泡内联样式（背景、描边、阴影、maxWidth）；motion 值与节点结构不变（message-motion-browser 只取 `.ice-message` 的 transform/opacity）。
- `styles/feedback.css`：`.ice-quick:hover/:active` 去掉 transform 与大阴影。

`docs/v2.0/KNOWN_ISSUES.md`：KI-004 追加复核记录。

## 本轮实际做过的检查

- TSX 语法：用 `tsc --noEmit` 对改动的 4 个 TSX 文件检查，无 TS1xxx 语法错误（缺依赖导致的模块解析错误不计入，**不是类型检查通过**）。
- 用真实 tokens/base/components/feedback/island/conversation 样式表 + 按 WorkbenchShell 结构手写的 DOM 在 Chromium 渲染：1440 宽三岛、专注模式、800 宽单岛；测得 `.ice-shell` 宽 = 视口，专注时 `#ice-writing-pane` = 1440、窄窗口 = 800，无横向溢出。**这不是应用真实渲染**，真实数据下的高度、滚动与弹层需本地确认。
- 静态检索了 layout-native、message-motion-browser、reading-lifecycle-*、dialog-layout-browser、ux-polish-native 等测试对文案/类名/样式的依赖，未发现被本轮改动破坏的断言；未逐一检查全部测试文件。
