- `MODES`/`isStreaming`/`END_NOTE` 常量随 Composer/MessageBubble 迁移。

5. 每步后跑：`check:ui`（tsc）→ `node --test tests/*.test.cjs` → `build:ui` →

  **已验证可行**（ArticleEditor 懒加载在生产 ui-smoke 中工作）。

### 4.2 方案 A（低风险，推荐先做）：弹窗宿主懒加载

`main.tsx` 中四个设置类宿主是纯"store 开关才渲染"的 Dialog 宿主，却全部 eager import：
`ModelSettings` / `BrowserHost` / `BackupSettingsHost(+Notice)` / `EditorialHost` /
`PublicationSettingsHost`。改成 ShortcutHelp 同款模式：

```ts
const ModelSettings = lazy(() => import("./app/ModelSettings").then(m => ({ default: m.ModelSettings })));
// ...同理其余四个宿主；BackupRestoreNotice 保持 eager（常驻横幅，体积小）
```
预期：入口显著下降（模型设置/备份/编辑工作台均为中重量模块），首屏仍完整。
验证：`build:ui` 产物列表 + ui-smoke + 各设置入口原生点开（settings/
backup-native/editorial-native 既有旅程复跑）。

### 4.3 方案 B（方案 A 后评估）：manualChunks 显式分组

```ts
build: {
  rollupOptions: { // rolldown 兼容层同样读取
    output: {
      manualChunks: {
        "vendor-react": ["react", "react-dom"],
        "vendor-query": ["@tanstack/react-query", "@tanstack/react-virtual"],
        "vendor-motion": ["motion", "radix-ui"], // 按实际包名
      },
    },
  },
}
```
注意：包名需与实际依赖树核对（radix 是多包）；分组过细会增加 ice:// 下的请求数。
**验收必须包含**：dist 文件清单、入口 chunk 体积对比、`check-asar-ui.cjs` 扩展
（当前只查 ui/dist/index.html 与主 bundle——多 chunk 后需校验全部产物在 asar 内）、
离线 file:// 加载无 CSP 违例（DevTools console 零 error）、ui-smoke/dpi-smoke 通过。
不许只报告"入口数字下降"。
