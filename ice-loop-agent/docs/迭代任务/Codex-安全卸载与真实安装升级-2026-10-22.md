# 安全卸载与真实安装升级（2026-10-22）

本轮发现并修复卸载递归删除安装目录的问题。卸载现在只删除编译清单内、内容未变的程序文件；额外文章、配图、工作区及修改过的文件保留。真实独立 NSIS 旅程23项、Node267/267、安全删除6组、两份候选的冻结新工作台20项分别通过。仍为2.0.0-beta.2，未提交、推送或操作个人正式安装。

## 修复前的真实复现

独立产品身份安装旧模板后，在程序目录创建从未属于程序的 my-articles/do-not-delete.md。卸载真正结束后文章消失。证据：`.test-tmp/installer-validation/00f1a130-7810-4b2d-a986-e2a5a60f2ed7/baseline-terminal-probe.json`，article_exists=false，两个注册表视图中的测试键和测试进程均为空。

最初观察父卸载进程返回0时文件仍在，出现假通过；其自复制子进程随后才删除文件。最终结论以子进程、文件和注册表终态为准，不能仅看启动父进程的返回。

## 生产改动

- `build/install-file-manifest.cjs` 在afterPack生成实际文件路径、长度、SHA256，拒绝链接，采用流式哈希；afterSign可重新生成。当前未签名，不声称签名链已验证。
- 清单保存在候选release/install-files.json，并在编译时嵌入卸载器；不信任安装目录内可编辑的清单。
- `desktop/installer/remove-owned-files.ps1` 先验证全清单再开始删除：拒绝相对/盘符根/共享根、路径越界、重复（含大小写差异）、ADS、非法名称及junction/symlink；删除前再次检查文件内容。
- 长度和SHA均匹配才删除；修改文件保留。只移除清单文件的空父目录，不递归清空安装根。输出removed/preserved_modified/missing/errors；失败返回23，阻止继续卸载。
- 使用.NET FileStream与SHA256并在finally释放，避免依赖某些宿主无法加载的Get-FileHash。
- `installer.nsh` customRemoveFiles替换上游RMDir /r；另外删除NSIS卸载器自身，再尝试非递归空目录删除。不安排重启后删除整个安装目录。
- 原有目标目录停止进程、工作区暂存和恢复保持。旧卸载器仍可能递归删除，因此覆盖安装前仍将识别出的工作区移出其范围，再恢复原路径。
- ZIP-only没有NSIS目标，不能等待其未初始化的内部选项Promise。钩子已按目标判断，仅NSIS目标解析helper；限时回归和实际ZIP-only构建均通过。

## 实际 NSIS 验收

可复验入口：`node build/installer-validation.cjs <已审计候选绝对路径>`。每次随机appId/GUID，目录为`.test-tmp/installer-validation/<UUID>/program with spaces`；禁用快捷方式、自动启动与测试安装器提权，只查改随机测试注册表身份。

为遵守非C盘运行要求，测试适配器仅将上游复制安装器缓存的目的地改到自有E目录，提取、注册、停止、保留和卸载逻辑保持。编译时断言GUID并固定助手源码。实际EXE与ASAR核对已审计候选。正式身份/机器级权限/正常缓存目录仍需另验，不能用测试身份代替。

23项实际检查：

1. 新装到含空格目录，实际冻结引擎启动；六家供应商没有Key。
2. 通过真实桌面CDP桥创建会话，在安装目录内保有真实SQLite工作区；另起一个独立ICE实例。
3. 运行中同版本覆盖：目标退出，另一实例存活；文章、额外图片和工作区文章SHA不变；工作区回到原路径；ASAR与候选一致。
4. 真实重开可读回原会话，仍无Key。
5. 运行中卸载：只停目标，另一实例保留；EXE/ASAR移除；修改过的LICENSE、额外文章/图片、数据库/settings均保留。
6. 卸载后两个注册表视图的测试键移除；包内Python只读打开保留的SQLite：creative_conversations=1，model_invocations=0。

这23项是同版本覆盖安装，不是1.5.x→2.x历史升级，也不代表向导所有页面与物理DPI已经测试。卸载旅程使用复制到测试目录并带_?=参数的标准方式，与builder覆盖升级一致；不声称已遍历用户双击向导。

## 失败与纠正

1. 直接加载NsisTarget出现builder循环初始化错误，改为先加载electron-builder；当时尚未安装。
2. 旧测试采用raw /D参数，空格路径被StdUtils截断；仅卸载该随机身份的错误测试目录，改用正常Windows参数转义后完整路径通过。不能据此判断交互选择目录有缺陷。
3. 父卸载进程退出不等于子进程结束，修复观察判据，最终真实复现文章丢失。
4. Get-FileHash缺失，换.NET流式哈希后六组通过。
5. 初始化builder前等待NSIS_PATH导致无活动句柄时进程提前结束；测试改复用审计清单，新增beforeExit失败记录，并同时核对退出码与结果状态。
6. 同类等待影响ZIP-only钩子，按目标判断后，实际ZIP构建与20项冻结测试通过。
