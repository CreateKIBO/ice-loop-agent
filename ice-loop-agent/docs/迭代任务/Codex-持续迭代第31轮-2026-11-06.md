## 检查范围与修复

围绕保存/恢复、AI提案冲突、提问框输入、图文交付与窄窗口操作检查，形成四组修复。没有新增通知优先级或全局队列。

1. **类型与入口**：两版对照提示对 `unknown` 元数据直接做 JSX 与运算，`npm run typecheck` 退出2；条件改为显式 Boolean 后通过。
2. **AI提案的原稿保护**：后端只比较纯文本，用户后来调整颜色/字号/链接/对齐时仍会套用旧提案；图位建议仅确认锚点存在，即使该段重写也可插入。现在保存并比较完整原块快照；过期提案仍可看，服务端拒绝采纳。编辑器用 ProseMirror 节点比较，在未自动保存的格式变化发生时即显示过期。早期没有快照的提案保留严格文字比较，不能用长锚点的80字摘要冒充完整匹配。
3. **提问框数据与键盘**：JSON草稿曾被按最终答案的2000字上限截断；多选加补充答案也会被静默截短。现将草稿存储容量与提交上限分开，保留完整输入；超过2000字明确提示并阻止提交。修复 IME Enter/Escape 误切题/收起、引用说明 summary 按 Enter 误提交、切题后焦点丢失；摘要/下拉菜单保留原生键盘行为，提交按钮按正常按钮行为确认。编辑标题的 Enter 同样避开 IME 确认事件。
4. **窄屏可达性**：新增插入工具栏在420px窗口横向溢出，中文按钮被挤成竖排。工具栏和按钮组允许换行、限宽并保留完整按钮文字。没有引入新的动画配方。

复用原测试时，旧过期提案用例声称只修改第二段，却同时删掉第一段的居中格式；修正夹具以保留第一段格式，再验证“未变段落可采纳、已变段落过期”，没有放宽保护规则。
