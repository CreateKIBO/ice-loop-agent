## 发现与修复

### 1. 命令面板同一时刻连点实际创建多个会话（P1）

原 `CommandPalette.execute` 只用 React `running` 状态判断。相同渲染闭包内连续调用三次，会在状态更新前同时通过守卫。隔离的真实 Electron + 实际后端复现出三条 `chat.create`，不是仅根据源码推测。

加入同步 `runningRef`，在任何 await 前置位，finally 释放。界面继续用 running 状态显示忙碌。新 `command-palette-native.cjs` 通过真实桥验证：三连点仅创建一次；失败保持面板并说明动作；解除故障后可以重试，重试只产生一次新写入。

修复前证据：`.test-tmp/codex-engineering-audit-20261022/palette-before.json`（writes=3）。修复后：统一验收 `native-evidence/command-palette/result.json`，7 项通过。

### 2. 播种和结果归档可能误报通过（P1，验收基础设施）

原入口只检查 seed 退出码，没有要求生成新运行目录。已有合法夹具存在时，零退出但不做任何工作的 seed 仍可通过。native 零退出且不生成结果也会使总报告 complete=true；若全局结果文件已有旧报告，还会归档旧结果。新增行为测试在修复前实际失败，分别记录于 `evidence-before.log`。

已修复：

- 播种前检查目录边界与构建依赖；构建失败不生成无用夹具。
- 播种后先校验所有权、目录联接和辅助路径，再归档；必须产生不同于旧夹具的新受控 runtime，否则 `blocked:stale-fixture`。
- 对结果计算执行前后文件签名，只复制本次实际更新的结果。缺失或旧文件不能成为成功证据。
- 结果必须对应本项 runtime，状态为 finished，checks 存在且全部为布尔 true。零退出但报告失败、运行目录错误或断言失败都导致总验收失败。
- 保留真实子进程 exitCode，另记 evidenceStatus，避免混淆“程序退出成功”和“验收证据不合格”。每项新增 evidence.json。
- 失败只阻断对应专项，独立项仍继续；默认不自动播种的行为保留。

PS5.1 行为回归 9/9；包含默认不开播种、失败隔离、目录/联接边界、依赖跳过、空操作 seed、缺失/旧结果、错 runtime、失败状态与 false 断言。这 9 项已包含在 Node 244 中，不重复计数。

### 3. StrictMode 专项的关键前置条件不完整（P2）

原脚本最后的“打开态卸载”发生在 Guard 场景之后，此时命令面板已关闭；移除/禁用 opener 场景也没有证明该控件曾获得焦点。另有计时器转发包装丢弃回调参数的问题。

已补真实前置条件：卸载前重新打开面板并确认输入聚焦；移除/禁用前先聚焦 opener 并留证；只把目标焦点计时器的 pending 取消计为目标证据。计时器包装完整传递回调参数和 this，并有运行断言。Electron TEMP/TMP 限制在本轮目录，finally 等待或结束自己创建的进程。

增强后 15 项通过；原 StrictMode 轮询专项另跑 4 项通过。原新脚本里“轮询有推进”改名为相应的真实含义，不单凭该计数声称只有一份轮询。

### 4. 编辑器多旅程与入口夹具证据不对应（P2）

原 editor-debounce 在入口已经播种后再次重播第一条旅程，外层 fixture 快照并非实际消费的数据；结果也没有 runtime 字段。“新建一次”的断言仅检查存在一次成功记录，并未限制次数。

现在第一条旅程使用入口生成的独立夹具，之后两条各自重新播种；报告保存各旅程 runtime 与 fixture 快照路径。主 runtime 与入口快照一致。精确断言一次新建；计时从输入前开始，删除未使用的 `|| true` 占位。真实回读三条工作草稿均包含最新输入，本轮导航发生在输入后的 18/15/24ms，自动保存尚未开始。

### 5. 配图租约检查存在不完整仍结束成功的分支（P2）

原脚本在图位不足时把“未验证”字符串写进 checks，仍可能 finished。改为缺少必要多图位夹具即失败。继续使用真实 Image onload/onerror 检验 blob 生存与释放；修正残留 fetch 注释。8 项通过，包含迟到响应确实到达后页面不重建原图。
