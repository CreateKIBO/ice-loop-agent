## 发现与修复

### 1. 测试包装器没有执行浏览器处理函数

`seed_interaction_lists_native.py` 原生成脚本仅在 ice:request 分支调用 fn；所有其他 handle 分支直接返回块作用域之外的 result。独立 VM 复现证明原浏览器函数调用次数为 0，异常为 `result is not defined`。这不是生产浏览器请求没有返回。

抽出仅供测试的 `desktop/tests/ipc-observer.cjs`，任何 handle 通道都恰好转发一次，返回值与异常保留。浏览器视图 ID 在处理完成后读取。新增六项 Node 行为回归覆盖通道转发、实际拒绝、未完成调用、故障注入、视图 ID 及真正的响应延迟。

原始 requests.jsonl 只有成功完成记录，没有记录真实拒绝。现在 requests.jsonl 仍是完成回执；invocations.jsonl 另外记录关联 ID、started/resolved/rejected、耗时。延迟已经算完的响应时记录 handler_returned。日志不写正文、凭据、完整参数或原始错误文本。

### 2. “任务按钮不生效”来自无检查点的夹具

旧 seed 直接插入 articles/jobs 行。生产 `_job_app` 正确拒绝这种不完整任务；独立记录中 jobs.stop 在 8ms 返回“任务检查点不存在，请从备份恢复后重试”。原日志不记录该拒绝，因此被当成没有调用处理函数。

新 seed 通过真实 engine.create_job 建立任务与检查点，完成稿经离线 Mock 工作流生成正文和真实本地运行证据，另有真实图片候选。只固定测试 ID，不伪造引擎执行结果。运行中快照模拟仅修改已存在有效检查点的任务状态；验收不声称它是真正持有工作线程租约时的网络取消。

新增独立原生旅程验证：单次 Enter 触发 jobs.stop，完成后才发 jobs.archive；单次续跑进入真实审批；单次“编辑正文”打开真实正文；工作草稿写失败阻止归档并保留输入，解除故障后同一入口可以落盘继续。

### 3. 真实产品缺陷：全局撤销三连点发出三次写入

GLM 给重命名/候选/列表/任务加了 ref，但全局 ToastAction 仍仅依赖 useState。真实 Electron 同 tick 三连点撤销得到 3 次 chat.update。

`components/toast.tsx` 现在用同步 ref 防止动作重入，处理中停止通知倒计时。原生修复前保留 `undo_write_count=3`，修复后为 1；不是依靠后端幂等掩盖重复请求。

### 4. 真实产品缺陷：关闭原图后未返回缩略图焦点

共享 Dialog 使用受控 Root、没有 Radix Trigger；本地依赖的 modal 默认关闭逻辑只尝试聚焦 Trigger，并阻止 FocusScope 的默认返回，所以原图关闭后焦点丢失。

`components/ui.tsx` 在打开时记录实际 opener，在关闭时仅恢复仍存在、可操作且不越过新弹窗的目标。嵌套原图可回到缩略图；旧弹窗关闭并打开新弹窗时不抢走新弹窗焦点。原生修复前焦点断言失败，修复后通过；弹窗矩阵与旧综合/图片流程均回归通过。

### 5. 帮助与原生断言中的漏项

帮助白名单声明了 publication-history，实际没有入口；新增“找不到旧文或期号不一致”的排障入口，打开真实“历史与目录”标签。四种帮助目的地均实测，不以任意 dialog 存在代替目标页正确。

旧脚本对 Radix 标签页调用 DOM click，未触发其激活逻辑；身份入口仍能从未切换的指南页打开，不能证明排障页被访问。改用真实键盘激活并等待 active tab。修正 settings_initial_focus 中“只要有 dialog 就通过”的空断言，移除 Esc 失败后另点关闭与重复 Enter 的替代路径。

浏览器恢复断言只比较 show/hide 生命周期事件，尺寸更新 bounds 另行观测。一次真实失败是 bounds 在 show 后到达导致“最后事件必须是 show”的测试错误，未修改产品来迁就该断言。

异步回执的重试现在必须观察到真实读取，不接受仅等轮询自愈；持续故障必须生成新的警告。迟到账号响应测试先证明 A 的数据已经算完，再延迟送达并切到 B，不能用一个被延迟的 B 请求代替 A 的迟到响应。

### 6. 验收入口与文档

`verify-workspace.ps1` 注册 interaction-integrity；fixture 守卫明确约束 trace/fault 为同一测试 owner 内的绝对路径，并有 PS5.1 行为回归。测试指南改为每个专项分别播种，修正控制字符损坏的命令。原 GLM 报告保留，并在开头标注结论更正；旧探针保留为历史诊断材料。
