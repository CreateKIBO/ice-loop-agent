## 产品改动

1. **剩余时长属于通知条目**。新增 ToastLifetime 保存剩余时间与活动起点，使用单调时钟；对象本身没有定时器或订阅。当前卡片仍负责自己的单次 timeout，暂停/卸载时清理并结算已读时间。portal 转移导致卡片重挂载时继续原时长，StrictMode 清理/重建不重置或重复扣时。原悬停、键盘焦点、隐藏文档、动作执行暂停语义保留。
2. **进度衔接**。卡片重挂载或减少动态偏好改变时，根据同一剩余时间计算 CSS 动画起始相位；普通重渲染不反复重设相位。保持原倒计时线、暂停状态及减少动态关闭动画，不增加循环或进度轮询。
3. **长详情可读可操作**。保留详情换行、限制详情高度并在内部滚动，模态宿主使用更紧凑高度，动作/关闭按钮留在详情外。实际溢出时才添加可聚焦的“通知详情”区域；短详情不新增 Tab 停靠点。ResizeObserver 仅用于测量实际溢出，卸载时 disconnect。原通知 status/alert、动作去重和错误脱敏保留。

没有修改 Dialog/Toast 宿主选择、portal key 或挂载方式，没有修改工作台、预算/消费者/后端或产品轮询。这里修复的是预期通知 portal 迁移的阅读状态，不能由此推出 D6 工作台异常瞬消已解决。
