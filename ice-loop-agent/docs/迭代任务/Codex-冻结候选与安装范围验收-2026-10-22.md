## 安装退出范围修复

`desktop/installer/stop-agent.ps1` 原来按同一 Windows 会话内可识别的 ICE 进程寻找根实例，可能覆盖其他安装和源码开发实例。现在由安装器明确传入 InstallRoot 与注册表记录的 PreviousRoot，标准化后按目录相等判断，拒绝相对目录、盘符根目录和无范围的真实停止操作。DiscoverOnly 仍允许只读观察。

子进程必须来自当前快照中的同一父进程身份，且创建时间不早于父进程；执行关闭前仍核对 PID 与创建时间。先发送关闭窗口消息，超过等待时间再停止已经确认归属的进程树。原工作区暂存／恢复流程保留。

NSIS 在停止前读取旧安装目录，向 PowerShell 同时传入新旧范围。参数末尾添加 `\.`，防止目录结尾的反斜杠影响 Windows 命令行引号解析。退出脚本失败时中止替换程序文件。

真实 Electron 多实例专项 13 项通过：正常退出及子进程退出、挂起实例强制退出、同品牌其他目录主进程和子进程均存活、登记的旧安装目录可停止、相对目录／盘符根目录／缺范围拒绝停止。测试只管理自建实例，不拿用户安装作夹具。

## 可重复的隔离发行入口

- `build/build-release.ps1` 与 `npm --prefix desktop run release` 统一进入 `build/build-candidate.cjs`，默认生成 NSIS 与 ZIP 并验证实际冻结桌面。
- 每次创建 `.test-tmp/candidates/<日期>-<UUID>/`，独立 TEMP/TMP、PyInstaller 与 builder 缓存；不删除源码缓存，不回写 spec，不移动或覆盖旧 release。
- PyInstaller 复用稳定 spec，数据收集排除 __pycache__ 与裸字节码，绝对项目路径避免 cwd 依赖；关闭 UPX。
- 包内只准备教学 Python 与声明的发布资源，不拷入用户数据库、设置、Cookies 等运行文件。审计中的文件名扫描有明确范围，不能等同于完整秘密扫描。
- 构建默认 `--publish never`，不继承签名／发布凭据。构建和校验各步记录退出码、日志、耗时、输入摘要；构建期间或验证期间源码变化均失败。
- 校验失败后候选标记 failed；通过后 verification 区分 payload-verified 与 payload-and-desktop-verified。built 仅表示构建阶段结束，不单独代表可发布。

### 产物审计

ASAR：99 个实际 UI／主进程／renderer 文件与源码字节一致，包含新工作台资源及 workbench-methods.cjs。package.json 的运行字段分别比对，因为 electron-builder 会正常删除开发元数据，不能拿整文件字节比较误判。

ZIP：逐文件流式比对全部 865 个文件的 SHA256，拒绝路径越界、重复条目和符号链接。NSIS 在 ZIP 已归档后可能向 unpacked 添加 `resources/elevate.exe`；仅允许这一项差异，而且要求其字节与本候选缓存中的 NSIS 助手一致，其他差异仍失败。

NSIS：流式读取真实安装器中的 EXE、ASAR、引擎、教学 Python 与 BUILD.json 五项，与 unpacked 比对长度及摘要。七张已批准品牌图与源码原图逐一字节相同。此项是安装载荷审计，不能代替真实安装／覆盖升级。
