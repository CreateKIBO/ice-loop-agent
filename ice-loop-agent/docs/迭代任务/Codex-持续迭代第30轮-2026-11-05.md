# 第30轮：写作技能选择与修改

日期：2026-11-05。输入 main@480e83a；功能分支 `codex/skills-settings-2026-11-05`。按用户要求实现技能选择与修改的首期功能。

## 使用方法与范围

新工作台左下角“写作技能”，或 Ctrl+K 搜索“写作技能”。

- 按公众号选择一个主写作技能，或选择“不使用额外技能”。
- 预置“通用写作”和“ICE 写作方法”。ICE 原账号默认选后者，其他公众号默认通用写作。
- 可修改名称与写作指令，新建/移除技能。移除保存后不会在重启时重新预装。
- 可直接修改固定结尾标题和编号选项；高级 JSON 支持标题长度、字数、代码范围/行数/注释、标点、禁用词和结尾关键词等。空对象不增加技能检查；清空结尾标题同时移除该技能的结尾三件套和品牌句检查。
- 显式“保存设置”后生效。脏编辑/保存中阻止导航；关闭、读取已保存内容需明确放弃未保存输入。并发保存冲突保留输入，不覆盖他处更新。

首期为单主技能，不含多技能组合、栏目/单篇覆盖、技能包导入导出、脚本插件、云端共享或技能版本历史管理界面。版本号、旧任务/回复的快照已接入。

公众号品牌、现有显式规则来源与单篇任务要求仍独立生效；技能不授予工具、模型预算、执行或发布权限。指令描述风格意图，确定性检查由结构化规则控制。

## 产品与后端

- `ice_agent/skills.py`：文本技能及白名单规则验证；公众号隔离；设置全量 CAS；每个技能内容变化时递增版本；启用技能解析为 profile，未启用时使用无作者个性化方法的基线。默认 ICE 保留原有编号、套话模式与周刊检查；套话模式只允许启停程序内预设，不接受自定义正则。
- 新增 v22 `writing_skill_settings` 迁移，使用现有事务/校验框架；未修改旧迁移函数及其校验和。
- `skills.get/save` 经 Workbench 注册，`desktop/workbench-methods.cjs` 显式开放对应 IPC 方法。
- `DesktopService._app` 在既有 RuleSources 之前应用技能；现有任务由 `rules_profile_snapshot` 恢复原设置。默认 demo fixture 保留原规则路径。
- `prompts.render` 对已解析技能走配置驱动的节点职责，不继续套固定的 ICE 风格模板。结构/品牌检查消费同一 profile；允许无固定结尾、无强制章节，风格规则可停用，事实与证据检查仍执行。
- `creative_chat` 从 resolved profile 生成请求，将写作 profile 保存到 request_snapshot；重试/澄清续接保留原快照。后台生成按原公众号构建 app，避免活动公众号变化影响归属。
- Agent `resolve_brand_rules` 读取真实生效规则；聊天工具循环使用该次请求的冻结 profile，避免工具回执与原请求矛盾。
