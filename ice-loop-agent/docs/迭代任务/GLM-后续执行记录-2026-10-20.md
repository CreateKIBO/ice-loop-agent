## 真实失败与修复记录（保留）

1. **widths-smoke 首跑**：注入目标为空 + 视口钳制在 1026。两个根因：窗口 minWidth 1040、注入发生在页面加载前（loadURL 已 await，did-finish-load 不再触发）。修复：仅该模式放宽最小窗宽；轮询 isLoading 后再注入。首跑失败报告保留在 `.test-tmp/widths-smoke-1792479952090`（无 report.json）。
2. **verify-workspace 三处自测失败**：(a) PS5.1 把无 BOM 的 UTF-8 脚本按 ANSI 解析→加 BOM；(b) EAP=Stop 把 npm stderr 进度当终止错误→步骤内临时放宽；(c) node-check 两步 WorkingDir 误传 $desktop 与 `--prefix desktop` 叠成 desktop\desktop→改 $repo。调试轮次日志保留在 `.test-tmp/verify-workspace/debug-cwd*`。
3. **native:onboarding 经入口首跑失败（30 项中第 1 项超时）**：等待"已配置的模型尚未接入写作"，实际显示"模型已就绪"——夹具库被此前运行推进过（陈旧状态），非产品回归。按规程重新运行 `seed_onboarding_native.py` 生成新隔离夹具后同入口通过（6.1s）。失败日志：`.test-tmp/verify-workspace/native-onboarding-check/native_onboarding.log`。
4. **async-recovery 测试三轮修正**：模块实例不共享（改 stdin 合并入口）、peek 返回 null 非 undefined、失败计数配置错误。均为测试自身问题，无产品代码改动。
