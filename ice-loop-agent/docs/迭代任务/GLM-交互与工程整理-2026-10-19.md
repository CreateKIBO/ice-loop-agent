## 十二、推荐执行命令

先从实际 `package.json` 确认命令是否仍存在。下面在应用根执行；每项检查真实退出码。

```powershell
$ErrorActionPreference = 'Stop'
$env:PYTHONUTF8 = '1'
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:TEMP = Join-Path (Get-Location) '.test-tmp\glm-checks'
$env:TMP = $env:TEMP
New-Item -ItemType Directory -Path $env:TEMP -Force | Out-Null

npm.cmd --prefix desktop run check
npm.cmd --prefix desktop run check:tools
npm.cmd --prefix desktop run check:ui
npm.cmd --prefix desktop test
npm.cmd --prefix desktop run build:ui
.\.venv\Scripts\python.exe -X utf8 -B docs/上线准备/run_full_checks.py
```

PowerShell 的 `$ErrorActionPreference` 不自动把所有 native 非零退出码变成异常，编排脚本必须显式检查 `$LASTEXITCODE`。本机 Node 位于 `E:\Node\node.exe`、npm 位于 `E:\Node\npm.cmd`，PATH 不含时显式使用或在当前进程加入 E Node；不要改系统全局配置。其他机器按其实际数据盘路径配置。

Native 入口示例：`desktop/tests/onboarding-native.cjs`、`layout-native.cjs`、`chat-window-native.cjs`、`editorial-native.cjs`、`assets-native.cjs`、`backup-native.cjs`。运行前阅读对应 `tests/seed_*_native.py` 的参数/输出协议并创建自己的隔离夹具；不得凭历史报告猜运行目录，更不能用已被清理的目录继续验收。

## 十三、测试场景与报告要求

至少真实覆盖下列贯通场景，场景内可复用夹具但不能共用个人数据：

| 场景 | 必须验证 |
|---|---|
| 新账号零数据 | 空状态可操作，不自动填入他人历史 |
| 两账号有重名栏目/会话 | 切换及延迟响应不串正文/候选/图片 |
| 初稿生成与保存 | Mock 输出→候选→失败留存→保存→侧栏出现→提交审阅 |
| 正文正在修改时切换 | 保存/放弃/留在当前各自行为正确，失败不离开 |
| 历史长会话 | 旧页位置保留、新消息提示、当前窗口查找、回最新 |
| 大纲与第 100 期 | 保留全历史和前五全文，手选题锁定，下一期对应 101 |
| 配图与内嵌网页 | 原图可开关、提示词不丢、网页收起不重建登录环境 |
| 键盘与窄窗口 | 焦点恢复、隐藏区不进入、缩放后主操作可到达 |
| 故障 | 超时/预算/陈旧版本/缺失资源显示真实原因，不伪成功 |
| 备份恢复 | 仅隔离目录、预览/确认/暂停任务边界，取消无副作用 |
