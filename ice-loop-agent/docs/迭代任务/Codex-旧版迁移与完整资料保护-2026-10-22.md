# 旧版迁移与完整资料保护（2026-10-22）

本轮继续处理历史卸载器的目录递归删除风险，以及安装失败和进程中断后的恢复。仍为 2.0.0-beta.2，不更改个人安装、版本号或 Git 提交。

## 状态

独立旧版安装机制迁移验收完成。2026-10-23继续收尾时再次核对295个输入与候选完全一致；整体上线目标仍开放，正式身份和历史数据库等边界见后文。

## 主要行为

- 升级前把完整旧目录同盘暂存到旁边的 .ice-install-recovery/<事务ID>/，包括散落文章、图片、工作区、未知文件及链接本身。
- 安装模板在提权后、写文件前明确执行保护，并移除调用旧卸载器的路径。
- 新程序按编译清单核对SHA；用户资料恢复原位。同名冲突保留在恢复点并记录于 ICE-UPGRADE-REPORT.json，不覆盖任一副本。
- 卸载只删除编译清单中内容未变的程序文件。可编辑的安装清单不是删除授权来源；生成的清单回执也必须与嵌入版本完全一致才能删除。
- 恢复记录写入并刷新后同盘替换，兼容旧写法中断遗留的完整 pending/previous 记录。
- 独立恢复注册项保存事务位置；新安装进程发现中断后先恢复再重试。身份、路径或权限范围不一致时拒绝继续。
- 回滚先关闭安装目录范围内进程；已整体恢复的根目录不重复回放移动日志。注册表保留值类型，恢复入口独立于旧安装注册项。
- 固定 electron-builder 26.0.12 模板适配；版本/锚点变化阻止构建。解压失败分支显式回滚并非零退出，不依赖静默模式不会触发的 GUI 回调。

## 真实缺陷与修复

1. 首次强杀 Commit 后主 manifest 消失而 pending/previous 仍在：18项中17过。修复记录替换与遗留恢复后19项过。
2. 回滚已搬回整体目录、尚未写终态时重试，会把旧程序拆散。按实际根目录状态跳过已恢复目录，并加重入测试。
3. 上游 UAC 内层实例跳过 CHECK_APP_RUNNING。保护改放必经位置，移除旧卸载器调用。
4. ZIP 解压错误直接 Quit，单靠回调不能恢复。错误分支显式回滚，验收器编译专用故障包运行该分支。
5. 新安装进程的临时 StageFile 不同，原先无法发现前次中断。加入持久指针与新进程回归。
6. 无注册记录但有效的 ICE 目录，提交时解析空 InstallLocation 会失败。先检查值存在再解析。
7. 恢复记录验证失败不能进入自动回滚。仅通过身份和路径验证的记录可驱动恢复。

8. 第一轮候选打包失败：custom script 配置跳过 builder 原有卸载器生成，提前声明函数还引用了未声明 installMode。改为在默认编译流程里替换经过检查的 section include，保留卸载器生成/签名流程；函数放到变量初始化后的 customHeader 宏展开位置。失败候选保留供审计，未安装。

9. 第一轮真实 NSIS 在准备阶段返回22；正常升级同样失败。最初怀疑重复展开长路径超出NSIS字符串上限；缩短后仍失败，因此该假设不能解释真实阻断。保护脚本本身单独调用可成功。改由脚本目录解析辅助文件，减少命令参数，并加与NSIS一致的调用回归。
10. 初版“退出22且资料在”的故障断言不足以证明进入解压分支。现要求持久事务确实 rolled_back，并在保留的 failed-new 目录发现真实已解压 ASAR。第一次11项局部检查不算回滚验收通过。
11. PowerShell 5.1 在参数默认值绑定时 PSScriptRoot 为空；将默认路径初始化移到脚本正文。首次新增全量286中有2项失败，修后两项定向复验通过，修复后当时完整Node286/286通过；后续DLL专项见下。
12. 一轮复制冻结引擎报 EBUSY，候选未通过载荷审计，未安装；没有证据把文件锁归因于具体软件。独立新目录重建。发现依赖清理可能重设退出码，参照现有builder CLI在exit事件保留失败码，故障配置实测返回1。
13. 另一轮构建期间修复上述默认值，输入摘要检查正确拒绝候选；随后在源码稳定状态重新构建。

14. 构建配置对象与默认配置合并导致extraResources叠加，存在混用全局旧dist的风险。改为传独立配置文件路径，载荷审计逐文件比对本候选dist的三个资源树，拒绝混合产物。
15. 完整NSIS诊断捕获实际错误：在插件目录作为cwd时，PowerShell 5.1的Add-Type将NSIS原生System.dll误作.NET元数据引用。最小探针没有该原生插件，因而不能复现。两个Add-Type调用改用已加载框架程序集的绝对路径；新增污染cwd回归先红。该回归首次修复后曾因复用已回滚StageFile而失败，按实际新进程使用新的StageFile修正测试前置。

## 验收设计

- 真实 Windows PowerShell 文件/注册表专项：冲突、链接、超长路径、值类型、重复执行、解压失败、强杀、新进程、重复回滚、非法身份与路径。
- 独立候选构建：冻结引擎、ASAR/ZIP/NSIS 审计、打包后的新工作台原生流程。
- 真实 NSIS：随机GUID、含空格E盘路径；旧递归卸载测试包→故障升级→正常升级→重启→安全卸载。另一个 ICE 实例应一直存活。
- 旧卸载器若运行会写外部见证文件，要求从未出现；文章、配图、数据库与会话必须保留。
- 故障包仅在隔离模板中将真实解压后的状态改成失败，以验证错误分支；这是故障注入，不冒称实际磁盘损坏。
- 旧包使用当前审计载荷，仅复现旧安装/卸载机制，不能当成1.5.x历史数据库迁移验证。
- 缓存、构建、运行数据位于项目 .test-tmp；只清除自有随机注册项，不递归清理个人目录。
