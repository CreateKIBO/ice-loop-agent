# 图片与网页资源释放

## 查看原图

在文章的配图工作台或配图资源箱，点击图片预览进入原图查看器。可选择“原始大小 100%”“适应窗口”，用加减按钮调整比例；图片大于窗口时可滚动或拖动查看。键盘加减号调整缩放，0 恢复适应窗口。

原图按需读取。关闭查看器、离开配图工作台或切换公众号后，本次图片显示地址会撤销。正式图片、已采纳候选和原文件保留；资源释放不等于删除文件。缩略图只在所属面板打开时持有显示资源。

若图片读取失败，可重试；公众号已切换、来源图片被改动或内容校验失败时应返回相应账号重新打开，必要时重新导入。程序不会为了恢复显示而绕过图片归属或内容校验。

## 网页工作台的三种离开方式

| 操作 | 作用 | 下次打开 |
|---|---|---|
| 返回文章 | 收起网页面板，保留已打开的站点 | 继续原页面 |
| 关闭并释放网页 | 关闭当前站点，释放其网页内容 | 当前站点从首页重新打开；其他站点仍可能保留 |
| 释放全部网页 | 确认后关闭当前公众号的所有站点及登录弹窗，取消未完成下载 | 各站点从首页重新打开 |

“释放全部网页”确认层显示当前站点和弹窗数量。“继续使用网页”取消释放，页面保持原样。释放前请保存网站内部尚未保存的内容，未完成下载会取消。已完成并保存的下载文件、公众号文章、图片资源及网站登录信息保留。退出确认不影响本地文章。

切换公众号沿用账号隔离规则，旧账号的网页不会留在新账号面板里。网页保留期间内存可能继续被网站使用；长时间不用时可显式释放全部网页。

## 内存读数的含义

关闭图片或网页后，程序会撤销图片地址、关闭文件句柄或销毁对应网页。Windows 与 Chromium 的缓存和内存回收存在延迟，任务管理器里的占用不保证立即回到启动时数值。关闭查看器不是删除图片，也不会扫描或清理其他目录。

本轮测试使用隔离的本地网页和大图，不等同于真实 TapNow、微信长期运行的耗用保证。出现持续增长时，请记录复现步骤、站点和操作轮数，再对照研发报告检查；不要按进程名结束所有 Python/Electron，也不要批量删除文件。
