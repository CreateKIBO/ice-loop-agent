# v1.4.1 修复说明

## 初稿失败的原因与修复

只读真实运行记录确认：模型三次都正常返回完整内容，程序要求严格 JSON 并报“找不到 JSON 对象”，因此没有建立候选稿。本版为创作对话接收完整 Markdown、Markdown 围栏及常见文章 JSON 包装，并补充系统层输出示例。不会把普通讨论自动当成文章；因长度限制等原因被截断的结果仍明确失败，不保存半篇稿。

同时修复正文一级标题校验误把代码块中的 `# 注释` 当标题的问题。长文格式修复保留全文，不再截取前 8000 字。原有模型 Key、选择和思考偏好保持；真实创作使用当前写作模型。

点击“生成初稿”完成后在右侧预览，选择保存或暂不保存。尚无会话时，填写会话信息后会继续开始初稿，无需再点一次。模型快速结束后按钮会重新启用。请求未能开始时，错误会保留在输入框上方，原输入与资料仍在；后台失败会保留原因，可以重新生成。

## 管理会话

会话工具栏新增垃圾桶按钮。归档及删除前都显示应用内确认窗口，删除移入回收站。点击查找会话，可选择最近会话、已归档或回收站，搜索、查看、归档、删除或恢复。未保存修改时先明确提示保存，不再静默无动作。

恢复后立即可以继续编辑；归档会话显示只读提示。删除会停止当前生成，保留全部历史与已保存稿件、审批。已保存稿仍在草稿箱，从草稿进入创作时不会复用隐藏会话。

## 管理制作任务

制作任务卡片和详情提供归档、删除入口；工作台“管理任务”可查看活动任务、已归档和回收站。恢复将任务放回活动列表并暂停，点击继续才运行。

运行中的任务先请求停止，仅影响当前任务的队列；已经开始的一段代码等待执行结束，后续代码段不再启动。当前执行尚未结束时提示“正在停止”，不能提前恢复。正文、配图、审批、证据和已导出文件保留，不因移入回收站而物理删除。已隐藏任务不能通过创作审批、配图或其他入口继续写入，先恢复后再操作。

## 验证边界

本轮使用隔离工作区、离线模型及本地受控 HTTP/SSE 服务，覆盖真实适配器返回和桌面点击流程。没有再次请求用户付费 API，也没有改动实际文章、任务或模型凭据。实际通过数量、日志、界面截图与安装包核对以 `v1.4.1-验收结果.json` 为准。

最终 142 项相关 Python 独立测试、35 项 Node 测试、源码与打包程序各 48 项桌面验收通过，重复运行不累加。安装器载荷、便携 ZIP、ASAR 源码与最新引擎一致。本轮未执行实际安装向导。

先保存当前编辑，再安装 `release/ICE-Loop-Studio-1.4.1-Setup.exe`，或者将便携 ZIP 解压到非 C 盘。升级后在旧失败会话中重新生成；旧版没有留下那三次失败的文章正文，不能从旧错误记录恢复。
