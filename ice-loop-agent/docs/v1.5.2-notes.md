# v1.5.2 调查笔记

确认旧补图任务创建时冻结max_model_calls=0，AI配图重拟复用其预算，被本地请求预留检查拦截。模型设置页的预算位于供应商卡片之后，当前文章缺少预算调整入口。需通过真实界面复查布局和交互覆盖。

新增预算回归不再模拟RoleRouter.generate，而是保留真实路由、预留和计数，仅使用离线适配器。在此测试发现配图重拟未恢复任务保存的模型配置，修复为该节点调用前restore快照。补图预算与正文预算分开；不开放补图任务的writer节点。默认预算写入使用与模型配置相同的settings锁，避免并发覆盖。

桌面验收脚本曾在executeJavaScript的最后表达式返回一个故意挂起的Promise，导致脚本等待自己的后续释放步骤；已通过void返回修复，没有扩大产品超时。复选框几何测试也改为等待真实弹窗动画完成再测量，不把动画期间的缩放误判成布局偏移。相关失败日志保存在隔离运行目录，最终结果只采用完成全部断言的运行。

Motion官方接口核对：https://motion.dev/docs/press ，https://motion.dev/docs/hover 。现有14.0.0本地包提供press/hover及清理回调。使用实际鼠标按压验证transform变化，DevTools仅对隔离窗口模拟系统减少动效偏好，并验证显式开启覆盖系统。

G盘空间不足时仅清理本项目.test-tmp的已生成安装载荷核对副本和Chromium缓存；保留旧正式安装包、数据库、截图、日志及用户真实安装。没有使用G:/pyshot_tmp。

真实几何验收还发现旧全局表单样式给复选框继承了39px的min-height。只设置height不能消除这个约束，已明确设定min/max-height=16px，同时检查宽和高。安装器载荷核对改为7za -so逐文件流式散列，并核对字节数及SHA256，避免为了验收额外占用约250MB磁盘；没有减少核对项目。

2026-10-05只读扫描G盘：约28.7万个文件，逻辑内容18.1GiB，磁盘已用57.3GiB。exFAT分配单元128KiB，小文件和目录的分配开销占主要空间；逐文件分配取整加每目录至少一单元的估算57.21GiB接近实际占用。扫描发现另一个项目wechat_app/miniprogram/.git报WinError1392，未触碰或执行磁盘修复。
