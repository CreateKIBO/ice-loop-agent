# v1.5.1 实现与验收笔记

本轮针对品牌配图提示词和内置网页空间；依据用户指定的AI/001提示词、正式视觉资产进行实现。最终程序已重建，验收使用该版本的内置引擎。

## 配图一致性

封面只使用对应栏目模板和正式头像作为有角色的参考图。现有封面使用编辑指令，只改标题和期号；与原稿不一致的模型分行建议会被拒绝。正文图明确逐字文字、元素位置与关系，身份图只作风格参考。其他公众号使用自己的品牌资产，显式general预设即使同名也不会套用ICE Loop。创作对话和工作流共用契约，确定性封面保护仅作用于明确为封面的新生成首条提示词，不改手工保存内容和正文图。

新增`prompts.references`与编辑器上传顺序、文件名、角色及预览；现有账号/图位/正文哈希保护和图片选择保留。初次原生验收发现桌面允许列表漏接该方法，补齐后源码和最终程序均通过。

## 网页操作空间

默认收起上方说明和底部流程文案，偏好持久化。扩大/恢复布局通过样式和原生视图区域更新实现，保持同一网页实例、地址与登录会话；导航和站点入口仍可操作。最小窗口与展开侧栏均验证了容器及原生网页区域对齐。

## 数据库锁根因

初次打包程序创作验收在首次生成时触发`database is locked`。`Store.__init__`每次打开连接都执行`PRAGMA user_version=9`，因此读状态也产生写竞争。修复为仅当版本不同才写。两项确定性回归分别检查读取不改变data_version、另一个连接持有写事务时能打开已有库读连接；修复前重现失败、修复后通过。保留默认超时、原schema版本及迁移行为，没有通过延长超时掩盖问题。
