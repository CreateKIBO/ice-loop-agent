# v0.8：栏目历史拟题与选题大纲

日期：2026-10-02。本轮修复标题上下文，并新增提前安排栏目题目的入口。

## 升级与开始

保存当前工作，关闭旧版窗口，再双击项目中的 `start-desktop.cmd`。已有数据库自动新增选题表和导入来源表，原文章、资源、模型设置保留。

左侧新增「栏目选题大纲」。新建文章的「题目来源」提供三个选项：

- **AI 分析历史**：分析当前栏目的历史，选择候选、修改确认，然后继续写作。最终标题工坊仍需审核。
- **栏目选题大纲**：选对应期的预设题目，点「采用对应期题」，修改确认后以该标题写作。
- **自己拟题**：直接输入最终标题，确认后写作。

大纲和自拟模式不调用 AI 重新拟题；骨架、正文、摘要、审校、配图继续走原流程，骨架和配图计划仍需审阅。AI 自动填充需求可补全读者收益等字段，但不改掉已经手动选定的标题。导入大纲无需配置模型；实际 AI 写作仍需配置可用模型。

## 历史拟题修复

此前存在三个问题：正文参考可能混入其他栏目；标题列表最多传 60 条；存稿索引只扫描目录前 500 项。现在按公众号和栏目隔离，去掉这两处条数截断。

「前五篇」按**所选期号之前、最近五个有正文的不同期号**取数。例如写第 12 期，优先参考第 11–7 期；其中某一期没有正文就继续向前找。同一期存在多个版本时优先用已发布记录。不拿其他栏目的正文补满五篇，不把后续期的正文作为此前知识。

模型还会收到该栏目的全部已索引历史标题，附期号与发布/草稿状态，以识别重复选题。已写出的后续草稿标题用于避免重复；正文仍只取此前五期。缺正文或不足五期时界面显示实际数量。

历史索引保留单文件读取边界：存稿正文文件最多 600KB、索引正文最多 200000 字符；本轮取消的是正文上下文原有 3500 字截断和条数截断。长栏目超过供应商上下文容量时可能需要换更长上下文模型；程序不会伪装成全部标题已经被模型分析。

## 导入大纲

1. 在「栏目选题大纲」选择「读取文档」，或直接粘贴文本。
2. 点「识别并预览题目」。这一步只解析，不保存或创建文章。
3. 检查栏目、期号、标题、内容要点、读者收益、下期预告；逐项修改，也可取消保留某行。
4. 点「确认并保存选题大纲」。遇到同栏目同一期已有不同题目时，需勾选覆盖确认；旧文章不会因此改写。
5. 在新建文章中选择「栏目选题大纲」，采用对应期题，修改后确认进入写作。

可用格式为 `.md`、`.txt`、`.docx`。文本支持 UTF-8/BOM，兼容 GB18030。Word 读取正文段落和表格；请先接受或拒绝未处理的修订。扫描件、图片中的文字、旧 `.doc` 和 PDF 不在本次支持范围。文件最多 2MB，解析文本最多 400000 字符。

识别按明确的栏目代号/名称、期号和标题进行，无需付费模型。无栏目、重复期号、不合规格的标题会显示问题，供你修改或取消保留；未识别行会提示数量。导入文本作为数据处理，不执行文档中的代码或指令。

每栏目支持 **1–9999 期，没有十篇限制**。一次导入最多 1000 条，支持多次追加。标题按当前写作规范最多 30 字。第 11、第 100 期可直接安排和选择。

## 示例文本

页面提供可复制/填入的示例，会按当前公众号的栏目生成。独立模板位于 `docs/栏目选题大纲-示例.md`，请先把栏目代号改成自己的栏目。

```markdown
# 我的公众号 栏目选题大纲

## PY · Python 从 0 到 1

### 第011期：把已有知识做成一个小作品
内容要点：回顾循环、列表与函数，完成一个可运行项目。
读者收益：独立完成并运行自己的小作品。
下一期预告：给作品加上输入校验。

### 第012期：让程序处理不合要求的输入
内容要点：用真实输入验证边界。

### 第100期：回顾自己的作品并继续改进
内容要点：从使用反馈中选择下一步。
```

也支持 `PY/011 标题`，以及栏目标题下面的 Markdown/Word 表格。表头可使用「栏目、期号、标题、内容要点、读者收益、下期预告」。不标期号的自由段落不会自动猜测为已安排的期题。

## 发布进度与标题确认

默认期号仍来自当前栏目的**真实已发布进度 +1**。保存大纲、导入草稿、选用未来第 100 期都不会把它标成已发布。要推进进度，请在「发布记录与历史」登记实际发布，或设置已有发布基线。

选用预设题目时会填入相应期号；你修改期号后，需要重新采用该期题目，避免把上一期的选择带到下一期。没有预设题目的期号可以切换到「自己拟题」或「AI 分析历史」。

创建文章时保存标题、来源模式、大纲条目与来源快照、人工确认记录。骨架和正文会沿用该标题，代码围栏中的 `#` 注释不改。之后修改大纲不会改变已经创建的文章。确认与创建之间若历史或预设来源变化，程序要求重新确认。

不同公众号的大纲和导入记录分别存储；已有备份/恢复包含这些表。当前栏目名称或来源变化时，过期的预览、选择和模型建议不会静默覆盖新内容。
