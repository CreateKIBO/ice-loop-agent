## 实现与故障边界

`ice_agent/backup.py` 写入、校验和提取使用 1MiB 分块，不再把每个图片/数据库成员完整读入内存。数据库校验和迁移在工作盘的临时副本上执行，不把整个数据库复制到内存。JSON 清单和配置仍需解析为对象；不能据此宣称整个应用 RAM 已降低某个比例。

备份拒绝目录联接和符号链接，包括文章根本身。单文件 128MiB、总托管数据 1GiB、10000 文件的现有限制保留。API Key、登录会话、日志和浏览器缓存不进入备份，外部只读素材目录不复制。

`BackupActions` 集中管理主进程选择器、10 分钟预览授权、单次恢复及互斥。Renderer 只能用已审阅 token 恢复，不能通过通用 request 指定任意恢复路径。恢复目录切换失败的重试同样使用主进程 token，不信任 Renderer 传入的目录。

任务 payload 的路径和规范 JSON 指纹一起迁移；使用与 `TaskQueue.enqueue` 相同的指纹算法，保持幂等域与 task/job 绑定。恢复标记阻止消费者对账自动重排；只有账号、任务指纹和状态匹配的显式继续能清除标记。备份前拒绝正在运行的创作回复/工作流/队列，认领队列任务与备份共享服务锁。

原生验收还发现：凭据解密失败时主进程调用旧版全局 `toast`，导致新工作台启动异常。现仅在存在旧版函数时调用；新界面继续通过 bootstrap 的 `credential_warning` 正常提示，原凭据保留。
