# 配图与内嵌网页迭代

当前目标仍是可分发的通用 Windows 桌面软件。本轮改动在源码中，尚未打入新发行包；没有修改用户文章、上传图片、生图、公众号发布或真实云模型计费调用。

## 用户现在能完成的操作

文章编辑栏新增“准备配图”；交付审阅里的“去配图”“准备图N”会进入当前文章的相应图位，无需退回经典界面。

1. 查看封面、真实截图和概念图示的图位位置、候选和有效状态；当前采用的候选排在前面，更多候选逐批展开。
2. 查看实际执行通过或预期报错通过的程序，选择与图位对应的运行记录生成截图。存在多段程序时不擅自选第一段，避免截错内容；后台继续验证源码、输出、正文及capture hash。
3. 导入图片并归档、采纳；或者在当前公众号资源库搜索名称/说明/标签并分页选择。每页最多加载12张缩略图，不把后续资源隐藏在固定前几张中。原生验收使用资源复用途径，系统文件选择器尚未自动验收。
4. 审核并采纳候选，或填写原因后否决；否决当前采用的图片会清除选择，交付审阅随即反映缺图。
5. 修改、复制并保存生图提示词，查看品牌参考图上传顺序；AI重拟复用现有文章/品牌接口，期间继续编辑时返回候选不会覆盖新输入。关闭及切图时保护尚未保存的提示词。AI重拟的晚返回编辑保护仍需原生专项验证，本轮原生只证明提示词编辑与保存。
6. 直接查看并调整本篇模型调用预算。1–100整数，不低于已用次数，携带limits hash；0不会被解释为文章无限额度，调整不重置已用次数。

## 原图与网页体验

旧的交付审阅“放大”只把1000×700缩略图铺大。本轮改为按需请求原图：支持适应窗口、100%、缩放、滚动和拖动；Escape关闭最上层原图窗口并返回配图工作台。原图不放入长期Query缓存，关闭时撤销Blob URL。原生已核对2400×1400实际像素，并多次打开关闭验证撤销。它不等于已证明整机RAM或所有解码缓存立即下降。

新工作台新增内嵌网页入口，配图面板可直接打开TapNow，导航栏也能独立打开网页工作台；支持切换微信公众号后台、HTTPS地址、后退/前进/刷新、加载状态及收起说明。网页区域随布局调整，不覆盖应用操作栏。

“返回文章”保留网页，方便继续操作；“关闭并释放网页”关闭当前WebContents及其关联弹出页，下次从首页打开，登录分区不删除。隐藏网页启用后台节流。远端页面继续使用独立账号/站点分区、sandbox/contextIsolation、无Node、无应用IPC。真实TapNow匿名站点的原生视图已测试，未登录或执行生图；微信公众号登录/发布仍需后续实测。

全局命令面板、模型设置打开时，原生网页会先隐藏，避免WebContentsView盖住应用弹窗；这条交互逻辑已实现，仍需专门的原生键盘与弹窗专项，不用网页尺寸通过来代替验证。

## 本轮发现和修复

- 原图Blob被本地页面CSP拦截。仅在img-src加入blob，同时保持本地脚本/连接限制，并禁止object/base/form导航。
- Radix Portal延后挂载，首次effect读取不到图片/网页容器，导致网页未挂载、原图尺寸监听未启动。改为跟随真实DOM节点的回调ref安装和卸载。
- 原图适应模式缩窄窗口后，横纵滚动条互相影响尺寸。适应模式约束画布及图片尺寸，原始大小模式保留滚动；800宽度实际复验通过。
- 测试曾误调未公开的slots.run_binding，被主进程拒绝。本轮没有为测试开放私有接口，改为核对真实asset.captured事件中run ID/源码hash/输出hash。
- 测试曾按“交付审阅”完整文本查找按钮，遗漏动态状态徽标。修正测试定位，没有为测试移除用户状态提示。

后续原生每轮证据目录含fixture ID及时间戳。同一fixture重试不会再覆盖前一轮结果；早期目录只按fixture命名的失败曾被重试覆盖，后续不将其描述为完整留存。
