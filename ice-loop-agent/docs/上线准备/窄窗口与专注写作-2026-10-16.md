# 窄窗口与专注写作验收

本轮修复小窗口同时挤压三栏导致正文难用的问题，并减少隐藏列表的后台查询。仅修改E盘当前工作区；保留已有未提交变更与个人运行副本。

## 最终行为

- 窗口宽度低于1080px时，导航、写作和任务分别占满内容区。工具条可随时切换；选择会话或文章后回到写作区。
- 大窗口保留拖动分栏，新增独立收起与专注写作。恢复时使用进入专注前的组合；临时缩窗不会覆盖大窗尺寸与显示偏好。
- 面板保持挂载。切换保留同一输入/编辑DOM、未发送消息、导航筛选与未保存正文；隐藏面板不参与焦点。Esc先清筛选，再返回写作区。
- 暂停隐藏侧栏的会话、草稿、任务与下载列表查询，后台制作继续运行。重新打开恢复刷新。偏好JSON损坏或写存储失败不阻止操作。

## 中间失败
