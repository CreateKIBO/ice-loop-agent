# ICE Loop Agent 优化与桌面界面交付

## 目标
修复审查发现的真实生产问题，交付具有 ICE Loop 品牌样式、连接实际 Python 引擎的独立桌面工作台。

## 决策
- 保留 Python 引擎与已有工作流，独立桌面使用 Electron，前端直接使用 HTML/CSS/JS 减少构建复杂度。
- 桌面通过受限 IPC + Python JSON Lines sidecar；worker 使用独立 SQLite 连接，不共享跨线程连接。
- 正式任务和离线演示显式区分；不默认触发付费模型和 TapNow 生图。
- 暖白 #F3F2ED、墨黑 #15191F、信号蓝 #2448DB；平面编辑工作台。
- 本轮优化与 UI 是交付范围；TapNow 登录后自动生图仍需要实际账号页面验证，界面保留手动导入闭环与入口。
