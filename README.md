# ICE Loop Studio

面向微信公众号创作者的 Windows 桌面工作台：讨论选题、生成和修改文章、管理栏目历史与视觉资产，在同一程序中使用 TapNow 和公众号后台，最后导出文章与图片供人工发布。

**当前源码版本：2.0.0-beta.2，仍在迭代验收。** 本仓库提交源码、测试和开发文档，不提供仓库内安装包或构建产物链接。历史报告中的安装包和本地测试目录不属于本次交付。

## 核心能力

- 多公众号档案、读者定位、栏目、品牌规范和历史文章导入。
- 类对话式创作，初稿候选、手动修改、保存草稿与提交审阅。
- 根据本栏目前五期正文和全部历史标题准备选题依据；支持导入大纲并选择指定期题。
- 任务、草稿与配图资源管理，真实执行证据、图片审核及原图查看。
- 内嵌 Chromium 使用 TapNow 与微信公众号后台；生图操作和最终发布由用户完成。
- 导出 Markdown、纯文本与已审核配图；本地备份、恢复及暂停任务的显式接续。
- 国内模型配置、写作分工、预算、输出上限和请求取消。
